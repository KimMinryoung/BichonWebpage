# 내전·국경 지대 사건 문서 재편 설계안 (2026-09-05)

대상: `/commulingo/events/civil-war`, `/commulingo/events/soviet-polish-war` 및 1918~1922년 묶음.
사건 문서 원본은 leninbot-pg `commulingo_history_events` (body_ko/body_en, timeline, locations, sources),
인물 연결은 `commulingo_history_event_people`, 용어 연결은 `commulingo_term_events`.
상태: 2026-09-05 구현·독립 검증 완료. 사용자의 배포 지시 후 운영 DB 반영 완료, 정식 화면 배포 진행.
사용자 수정: 상위 문서의 기존 인물 연결은 모두 유지하며, 하위 문서에 추가 연결한다.
결과와 검증 기록: [작업 기록](commulingo-civil-war-restructure/README.md).

## 1. 진단 (2026-09-05 DB 기준)

### civil-war 는 이미 사실상 상위문서인데 깊이가 들쭉날쭉
- 본문 9장 중 7장이 폴란드 전쟁+브란겔, 8장이 크론시타트·볼가 기근·극동을 길게 다룬다.
  그런데 soviet-polish-war, kronstadt-1921, volga-famine 문서가 따로 있다 → 중복.
- 반대로 발트·핀란드·우크라이나·독일은 하위문서도 없고 상위문서에도 없다.

### 발트 3국은 단어로만 등장
내전 본문에서 발트가 나오는 곳: 브레스트로 내준 땅, 나르바 전투(1918.02.23),
오룔 반격의 라트비아·에스토니아 소총병사단, 페트로그라드를 공격한 유데니치(1919.10). 이게 전부.
빠진 것:
- 에스토니아 독립전쟁과 타르투 조약(1920.02.02) — 소비에트가 국경을 승인한 첫 조약, 레닌의 「유럽으로 난 창」.
- 라트비아 3파전: 스투치카의 소비에트 라트비아(1919.01~05), 폰 데어 골츠 자유군단·발트 향토방위군, 니에드라 쿠데타(1919.04),
  체시스 전투(1919.06), 베르몬트-아발로프의 리가 공격(1919.10~11), 리가 강화(1920.08.11).
- 리투아니아: 카프수카스의 리트벨, 폴란드의 빌뉴스 점령(1919.04), 모스크바 조약(1920.07.12), 수바우키 협정과 젤리고프스키의 「중부 리투아니아」(1920.10).
- 에스토니아와 유데니치: 에스토니아 땅에서 출발한 북서군을 에스토니아가 승인하지 않고 무장해제한 뒤 타르투로 간 경위.
  현재 문서에서 유데니치는 이유 없이 등장하고 사라진다.
- 영국 해군 발트 작전(코원 함대, 1919.08 크론시타트 어뢰정 공격).

### 「열강의 개입」 장에 독일이 없다
- 1918년 최대 개입국은 독일: 우크라이나(스코로파츠키 헤트만 정권), 발트(오버 오스트, 발트 연합공국 구상), 핀란드(내전 파병 발트 사단).
- 1918.11 정전협정 12조로 독일군이 발트에 잔류 → 이듬해 자유군단 문제의 뿌리. 이 연결이 어디에도 없다.
- 오데사의 프랑스군(1918.12~1919.04, 그리스군 포함), 캅카스·중앙아시아의 영국군도 빠짐.

### soviet-polish-war 는 리가 조약이 4장 중복
- 「리가의 선」, 「네만에서 리가까지」, 「리가에서 팔아넘긴 것」, 「전쟁이 끝낸 것」이 모두 같은 조약.
- 얇은 곳: 북쪽 날개 리투아니아(빌뉴스·수바우키), 라트비아·폴란드 합동 다우가프필스 작전(1920.01), 페틀류라 쪽 우크라이나 배경, 프랑스 원조(베강 사절단).

### 구조 문제
- 사건 페이지에 상위·하위 관계 필드도 「관련 사건」 상자도 없다. sort_order 순 이전·다음 화살표만 있음.
- 검사한 7개 문서(civil-war, soviet-polish-war, kronstadt-1921, volga-famine, ussr-formation, winter-war, october-revolution)
  본문 원문에 다른 사건 문서로 가는 명시 링크가 0개.
- `data/commulingo/linkify.js`에 사건 항목 종류가 등록되어 있어(`/commulingo/events/<id>` href) 제목·별칭 자동링크는 가능할 수 있음. 실제 발화 여부는 확인 필요.

## 2. 설계안: 상위 1 + 하위 6

civil-war 주소는 유지하고 상위문서로 재편. 신설 3, 기존 하위 3 편입.

| sort | id | 기간 | 역할 |
|---|---|---|---|
| 35 | brest-litovsk (신설) | 1917.12–1918.11 | 브레스트 협상과 당내 논쟁, 독일의 동방 점령(우크라이나·발트·핀란드 내전), 11월 붕괴가 남긴 공백 |
| 39 | ukraine-1917-1921 (신설) | 1917–1921 | 라다, 헤트만, 디렉토리아와 페틀류라, 흐리호리우·마흐노, 데니킨 점령, 폴란드 동맹까지 키예프 정권 교체 |

### 내용 이동
- **상위문서에서 빼는 것**: 2장 「브레스트의 선택」 전반부 → brest-litovsk (상위에는 요약 2단락). 7장 폴란드 절, 8장 크론시타트·기근 세부 → 각 하위문서, 요약으로 대체.
- **상위문서에 넣는 것**: 3장 「열강의 개입」에 독일(1918)·프랑스(오데사)·영국(캅카스·중앙아시아) 추가.
  1920년 장에 「국경 지대의 강화」 절 신설 — 발트 조약과 리가 조약이 왜 같은 해에 몰렸는지 한 흐름으로, 하위문서로 넘김.
- **유데니치**: 페트로그라드 공격은 상위 1919년 장에, 에스토니아와의 관계·북서군 해체는 발트 문서에.
- **핀란드**: 1918 내전·독일 개입 → brest-litovsk, 1919~20 에스토니아 지원 의용군·타르투 강화(1920.10.14) → 발트 문서.
  winter-war 서두가 이미 짧게 다루므로 그쪽은 링크만.
- **우크라이나 문서**는 사용자가 묻지 않은 항목. 폴란드 전쟁 발단(바르샤바 협정), 독일 개입(헤트만), 데니킨 후방, 마흐노가 전부 여기서 만나므로
  없으면 문서마다 배경 반복. 범위를 줄이려면 이것만 뒤로 미룬다.

## 3. 함께 손볼 것

- **상위·하위 표시 장치** (권장: 후자)
  - A. 본문 절 끝 「자세히 보기」 마크다운 링크 — 무배포.
  - B. `commulingo_history_events`에 관계 jsonb 칼럼 추가 + 사이드 패널(`views/partials/commulingo-event-panel.ejs`)에 「이 시기의 문서」 상자 렌더링.
    ALTER TABLE은 postgres 계정으로(frontend 역할은 DDL 불가), 뷰 수정이라 배포 필요.
- **인물 등재**. 이미 있음: stucka, vatsetis, smilga, yudenich, mannerheim, kuusinen, carl-manner, skoropadskyi, petliura, makhno, max-hoffmann, yevgeny-miller, pilsudski, tukhachevsky, budyonny, adolph-joffe, chicherin, krasin, litvinov, radek, marchlewski, rakovsky, masaryk.
  없음(약 17명): 페츠, 라이도네르, 퇴니손, 울마니스, 니에드라, 메이에로비츠, 폰 데어 골츠, 베르몬트-아발로프, 스메토나, 볼데마라스, 카프수카스, 안가리에티스, 젤리고프스키, 부와크-바와호비치, 스빈후부드, 빈니첸코, 흐루셰프스키, 흐리호리우, 킹기세프, 안벨트.
  신규 인물 필수 세트(제 문자 이름 cyrillic 칼럼, origin/citizenship 코드+플래그 SVG 확인, 사건 relation_kind) 함께 채울 것.
- **사건·인물 연결 보강** (사용자 수정). civil-war의 기존 연결은 모두 유지한다. 발트·폴란드·우크라이나 문서에 인물 연결을 추가하고 신규 관련 인물도 상위 문서에 함께 연결한다. 기존 연결의 설명도 두 건의 사실관계 정정 외에는 보존한다.
- **되돌아오는 링크**: winter-war 서두(핀란드 내전·타르투), baltic-independence(1918 독립선언·1920 제헌의회), ussr-formation(1920 쌍무 조약 절).
- **국·영문 동시 작성**. body_ko/body_en, timeline·locations 라벨 양쪽.
- **진행 순서**: brest-litovsk → baltic-wars → (ukraine) → soviet-polish-war 정리 → civil-war 재편. 상위에서 먼저 빼면 사이트에 공백 생김.
