# 내전·국경 지대 재편 작업 기록

2026-09-05. 사용자의 인물 보존 지시와 운영 배포 지시를 반영했다.

## 반영 내용

- 브레스트(35), 우크라이나(39), 발트 독립전쟁(41) 문서를 국·영문으로 신설했다.
- 내전은 본토 전선 서술을 유지하면서 중복 절을 요약과 명시 링크로 교체했다. 독일, 오데사, 캅카스·중앙아시아 개입과 국경 강화를 보강했다.
- 폴란드 전쟁의 리가 관련 네 절을 두 절로 합치고 북쪽 날개·프랑스 원조를 보강했다.
- 크론시타트·기근의 기존 본문은 유지했다. 겨울전쟁·발트 독립 회복·소련 성립에는 돌아오는 링크를 추가했다.
- 관계 JSON의 parent를 기준으로 상위·하위·같은 묶음의 문서 패널을 렌더링한다. 존재하지 않거나 미공개인 문서는 표시하지 않는다. 기존 스키마·스냅샷에서도 동작한다.
- 신규 인물 20명을 등재하고 역할·원어 이름·국적·출신·출처를 채웠다. [인물 출처](people.md)에 불확실한 필드의 처리도 기록했다.
- **상위 문서의 인물 연결을 삭제하지 않는다.** 새 문서에 추가 연결하며, 새 관련 인물도 상위 문서에 연결한다. 기존 설명은 치체린의 조약 서명 주장과 카메네프의 총사령관 재임 시작 두 건만 정정했다.
- 브레스트 용어의 동일 주제 연결은 새 사건으로, 마흐노 운동 용어의 사건 연결은 우크라이나로 옮겼다.

## 검증

- 마이그레이션 전체 시험 실행 후 롤백 성공, 이후 운영 DB와 분리한 공개 사전 복사본에서도 적용 성공.
- 국·영문 20개 패널을 실제 라우트·EJS로 렌더링했다. 내부 사건 링크 목적지, 중첩 링크 부재, 상위 문서의 하위 6개 표시, 기존 인물 ID 보존을 확인했다.
- 검증 복사본에서 71개 사건의 locations/timeline geo 감사와 271,058개 필드의 script-leakage 감사 통과.
- audit-link-fires: 국·영문 각각 11,050개 공개 본문 검사. 새 인물 별칭의 문맥을 검토했다. 에스토니아 임시정부를 러시아 임시정부로 연결하는 발화와 브레스트의 일반적인 선택 표현에 붙는 철학 용어 링크를 차단했다.
- 호스트 테스트의 나머지 항목은 통과했다. test-error-page는 샌드박스 포트 제한으로 실패하여 제한 밖에서 재실행해 통과했다. 관계 전용 smoke 및 64개 EJS 컴파일 검사도 통과했다.
- 새 위치는 도시/항구 점 좌표이며 추정 국경선이나 현대 저수지 윤곽을 추가하지 않았다. 기존 전투 연표 geometry는 보존했다.

## 적용 자료

실행 원본: `scripts/migrations/164_commulingo_civil_war_restructure.sql`.
이 디렉터리의 `.ko.md` / `.en.md` 파일은 검토용 본문 사본이다.
SQL은 본문 해시로 동시 편집을 감지하며, 모든 변경을 한 트랜잭션으로 적용한다.
기존 인물 연결을 삭제하는 SQL은 없다. 기존 연결의 삽입 충돌은 기본적으로 보존한다.
운영 DB 적용은 사용자 배포 지시 뒤 완료했다. 화면 배포는 `scripts/deploy --restart`로 진행한다.
초기 원문 백업은 Git에서 제외되는 `temp_dev/civil-war-restructure-backup/`에 보관했다.
독립 검증 DB는 `commulingo_restructure_review_20260905`, `commulingo_restructure_final_20260905`이다.
