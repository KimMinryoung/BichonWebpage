# 노노그램 구현 참고

구현 갱신: 2026-09-06. 실제 운영 반영 여부는 컨테이너 revision으로 확인한다.

라우트는 `/nonogram/`, 기존 `?p=<id>` 링크를 유지한다. EJS/입력 UI는 `views/public/nonogram.ejs`, `public/js/nonogram.js`, CSS는 `public/css/nonogram.css`. 게임 카탈로그는 `/games/`이며 공통 crumb와 팔레트를 공유한다.

## 콘텐츠와 검증 기준

`public/puzzles/index.json`에 공개한 11개 모두 **단일해**다. 새 workers-* 6개는 5×5 망치·깃발, 10×10 공장·확성기, 15×15 국제주의 지구본·공산링고 정치학교(책+별)다. 공산링고의 주제를 새 픽셀 그림으로 재해석했고 외부 아이콘의 경로를 복제하지 않았다. 기존 그림·ID는 유지한다.

입문·중급·도전은 카탈로그 `difficulty`로 구분한다. 새 문제는 모두 행/열 후보의 공통 칸을 반복 확정해 추측 없이 풀 수 있어야 한다. 기존 민총이 15×15는 단일해지만 이 단순 줄 추론만으로는 끝나지 않으므로 도전으로 분류한다.

`public/js/nonogram-logic.js`는 브라우저 힌트와 Node 검증에서 공유하는 순수 함수다. `possibilities()`는 줄의 가능한 배치를 열거하고, `deduce()`는 모순/확정 과정/완성 여부를 반환한다. `solutionCount()`는 미정 칸을 분기해 두 해를 발견하면 중단한다. 0해 또는 2해 이상이면 공개 콘텐츠 테스트가 실패한다. 힌트 함수는 정답 비트맵을 참조하지 않는다.

문제 JSON은 기존 크기·힌트·solution·questions 구조에 질문별 `explanation`, 선택적 `source_url`을 추가한다. 기존 조작 퀴즈와 근거가 불명확한 연도·상징 일반론은 사이트 관련 맥락 질문으로 교체했다. 해설에는 마르크스/레닌 원문, 민주노총 공식 자료, ILO 자료로 가는 근거 링크가 있다. 출처를 확인하지 않은 역사 주장을 추가하지 않는다.

## 선택과 조작

- 명시적 `?p=`가 최우선. 없으면 마지막 미완료 퍼즐, 다음으로 가장 최근의 미완료, 없으면 5×5 망치다.
- 난이도별 접이식 목록은 줄바꿈하며 현재 문제 그룹을 펼친다. 완료/그림 해제·질문 남음/진행 중을 구분한다.
- 처음 사용자용 접이식 안내가 숫자 묶음과 빈칸, 입력 모드를 설명한다.
- 칠하기/X 모드와 우클릭 X, 한 스트로크로 여러 칸 칠하기, 키보드 Enter/Space 입력을 유지한다. 방향키로 이동하고 보드에는 하나의 Tab 진입점만 둔다.
- 되돌리기/다시 하기는 스트로크 단위이며 최대 100개를 현재 세션에 보관한다. 완료한 보드는 잠긴다. 초기화는 확인 후 해당 문제의 그림과 질문 진행을 초기화한다.
- 한 칸 힌트는 줄의 모든 가능한 배치에서 같은 값인 칸 하나를 표시하고 이유를 설명한다. 현재 표시가 정답과 모순되면 먼저 점검을 안내한다. 확정할 줄이 없으면 추측하지 않는다.
- 크게 보기는 36px 셀과 내부 가로/세로 스크롤을 사용하며 힌트는 고정한다. 판 맞추기는 기존 크기 계산을 사용한다.
- 퍼즐/목록 로딩 실패는 다시 불러오기와 다른 문제 선택을 제공한다. 요청 번호로 이전 응답이 최신 선택을 덮어쓰지 못하게 한다. 요청한 그림 대신 무관한 fallback 퍼즐을 표시하지 않는다.

## 저장과 완료

`nonogram-progress-v2`는 `{ [id]: { cells, revealed, answers, completed, updatedAt } }`, `nonogram-last-v2`는 마지막 문제 ID다. cells는 1(칠함), -1(X), 0(미정)이며 크기와 값을 검증한다. answers는 질문 번호별 정답 인덱스이며 현재 콘텐츠의 정답과 맞는 값만 복원한다. 그림 해제와 질문 전체 정답을 모두 충족해야 completed다.

그림 해제 후에도 판과 질문 진행을 남겨 재접속 시 곧바로 질문을 이어갈 수 있다. 기존 `nonogram-progress-v1`의 판을 가져오며 `nonogram-solved-v1` ID는 그림 해제로만 가져온다(질문 완료를 증명하지 않음). 구 키를 삭제하지 않는다. v2 초기화 기록이 있으면 구 기록을 재수입하지 않는다.

저장이 차단되거나 실패해도 메모리에서 계속 풀 수 있고 저장 실패를 안내한다. 계정/서버 동기화는 없다. 카탈로그의 선택 링크는 JS 없이 동작하며 진행 표시는 선택적 향상이다.
