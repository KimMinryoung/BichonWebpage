# 1905년 혁명: 제국 변경 절 추가 — 2026-10-02

인물 카드(얀 베르진 등)와 사건 연결 메모에는 발트의 1905년이 나오는데 사건 「1905년 혁명」 본문에는 없다는 사용자 지적으로, 별도 사건을 만들지 않고 같은 문서에 절을 더했다(사용자 결정). 1905년은 한 제국 안의 하나의 혁명이고, 사건에는 하위 사건 구조가 없어 문서를 나누면 같은 해를 두 문서가 나눠 갖게 되기 때문이다. 요약은 짧게 두고 설명은 절에서 한다(사용자 지시).

## 변경

- 본문 한·영: 「바리케이드 위에서 배운 것」 다음, 「올가미와 선거법」 앞에 절 「제국의 변경에서: 발트에서 캅카스까지」(7문단: 개관, 라트비아, 에스토니아·리투아니아, 폴란드, 핀란드, 캅카스, 진압).
- 요약 한·영: 첫 문장에 「발트·폴란드·핀란드·캅카스까지」 한 구절만.
- 연표 14 → 22: 리가 발포(1.26), 우치 봉기(6.22–24), 탈린 발포(10.29), 핀란드 대파업(10.30–11.06), 빌뉴스 대의회(12.04–05), 투쿰스 봉기(12.13–15), 발트 징벌 원정(1905.12–1906, 지도 점 없음), 구리아 공화국 해체(1906.03). 날짜는 기존 연표처럼 신력.
- 위치 3 → 7: 리가·바르샤바·헬싱키·구리아. 출처 6 → 17.
- `countries`는 `russia` 그대로다. 1905년의 발트·폴란드·핀란드는 직접 당사국이 아니다(마이그레이션 178의 정의).

## 수치 기준

출처마다 다른 수치는 범위나 「~측 집계」로 썼다. 리가 1월 발포 사망 56(라트비아어 위키)~130(영어 위키), 바르샤바 1월 90~100, 우치는 공식 151, 라트비아 진압은 라트비아어 위키 집계(무재판 처형 2,041, 시베리아 2,652, 망명 약 5,000), 에스토니아는 1906년 무재판 총살 300 이상. 바쿠 단체협약 「최초」는 소련 노동사 전통의 평가라 「최초로 꼽히는」으로 썼다. 트빌리시 세부(1905년 8월 시두마 발포 등)는 2차 자료 하나뿐이라 넣지 않았다. 얀 베르진의 1905년 행적(부상·사형 선고 여부)은 자료가 엇갈려 「열여섯 살에 무기를 들었다」까지만 쓴다.
