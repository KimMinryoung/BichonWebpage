원어 저본은 sources/, 선택 범위·해시·서지는 specs/, 검수 기록은 reviewed/*.review.json, 공개 파일 해시는 publication.json에 보존했다. 제목에서 발췌 표기를 제거했으며 기존 링크 호환을 위해 기존 문헌 ID는 유지했다. 베른슈타인은 1902년 제2판 서문도 포함한 전사본임을 명시했다. 후대 편집자의 현대적 해설은 번역 범위에서 제외했다.

번역은 기존 backend archival translation 파이프라인과 로컬 공급자 프록시를 통해 **deepseek-flash**로 실행했다. 프로덕션 공용 모델 설정을 변경하지 않았다. 재현 스크립트는 scripts/translate-course-fulltext.py, 검수·조립은 scripts/review-course-fulltext.py, 공개 반영은 scripts/publish-course-fulltext.py다. 번역 캐시·중간 출력·이전 공개본 백업은 현 호스트의 translations/와 previous/에 보존하며 Git에서 제외한다.

총 2,535개 원문 블록의 해시와 번역 완료 여부를 검사했고 최종 실패 청크는 없다. 표의 수치·셀 배열, 주석 왕복 링크, 원문 인용 경계, 표시된 잔여 외국어와 주요 문장을 대조·수정했다. 전문 번역가의 전 문장 교열을 완료했다는 의미는 아니다.

검증: npm test 전체 통과. 실제 브라우저에서 모바일 390px·데스크톱 1280px의 문서 페이지와 분할 페이지, 가로 넘침·주석 링크를 확인했다. 공개 도메인의 참고문헌 목록과 주석 이동, 제외 문서 404를 확인했다. 상세 결과는 browser-verification.json에 있다. host-mounted 문서 반영 후 Cloudflare의 문헌·목록·사이트맵 캐시를 삭제했다. 컨테이너 재시작은 필요하지 않았다.

기존 등록 큐 1977(오언)은 done, 1983(레닌)은 사용자 제외 사유와 빈 resolved_id로 정리했다. 과거 오언 미완료 인수인계는 종료했으며 미완성 Gemini 캐시를 다시 공개하지 않는다.

프랑스 혁명기 개별 문헌은 이후 [주제별 문헌집 4편](../commulingo-french-reference-collections-20260913/README.md)으로 통합했다. 이 배치의 publication.json은 통합 전 공개 기록이며, 현재 문헌집과 이전 주소 이동은 통합 기록을 따른다.
