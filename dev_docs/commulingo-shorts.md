# CommuLingo 쇼츠

구현: 2026-09-28(질문 카드), 2026-11-23 이야기 카드로 교체. 주소 `/commulingo/drill/shorts`, 학습 탭 줄의 「쇼츠」.

## 목적

생각 없이 위로 넘기며 읽는 피드다(소유자 요청 2026-11-23 「문제 푸는 거 말고, 쇼츠처럼 생각없이 볼 수 있는 거」). 질문·답 열기·보기·채점이 없다. 그 전의 「질문 → 탭해서 답」 카드는 문제 풀이와 다르지 않아 2026-11-10 훈련장과 함께 숨겼고, 이번에 카드를 바꾸며 쇼츠만 다시 열었다. 메뉴 키는 훈련장(`commulingo.drill`, 여전히 숨김)과 나뉜 `commulingo.shorts`다(`services/menu-views.js`, `config/hidden-menus.js`). 새 원고를 쓰지 않는다.

## 카드와 재료 (`data/commulingo/shorts.js`)

| 카드 | 재료 | 보이는 것 |
| --- | --- | --- |
| 장면 | 공개 강좌 편의 `storyCards` 장면 카드(첫 레슨) | 강좌 이름, 「장면 n / m」, 첫 장에 편 제목, 때, 제목, 줄. 마지막 장에 「이 편 강좌로 보기」 |
| 오늘의 역사 | 사건 연표 줄 가운데 `period.start`가 년·월·일인 것, 한국 날짜의 월·일 | 날짜, 해, 줄 제목·본문(420자 이하), 사건 버튼 |
| 인물 | 인물 카드의 `moment`(두 언어, 한글 40~260자) | 국적 국기, 이름, 생몰년·별칭, 결정적 순간, 「인물 카드 보기」 |

등장 세력 카드(`cast`)는 지도·막대 없이 떼어 보면 뜻이 약해 뺀다. 장면 줄의 세력 표식(`{{flag:…}}`·`{{pos:…}}`)은 지운다. 지도와 세력 막대는 그리지 않는다.

피드 응답 `GET /commulingo/drill/shorts/feed/<key>`는 언어와 무관한 이중 언어 JSON이며 세션 없는 공개 데이터 경로(`config/route-policy.js`)다: `e<n>` 편 하나, `p<n>` 인물 40명 묶음, `d<MM-DD>` 그날의 연표 줄(해 순). 강좌·인물·사건이 바뀌면 version이 바뀐다.

## 피드 순서 (`public/js/commulingo-shorts.js`)

- 첫 장은 오늘의 역사 한 장(그날 줄이 없으면 바로 편). 그다음 무작위 편 하나의 장면을 순서대로, 편 뒤에 오늘의 역사 한 장(남아 있으면)과 인물 두 장을 끼우고 다음 편으로 간다. 편과 인물 묶음 순서는 브라우저에서 섞고, 다 돌면 다시 섞는다.
- 「다음 카드」 버튼은 두지 않고 위로 밀어 넘긴다.
- 스크롤은 `scroll-snap`을 쓴다. 피드 높이는 상자 위치에서 계산해 한 화면에 맞춘다. 카드 높이는 피드 높이로 고정하고, 글이 넘치면 카드 안에서 스크롤한다. 카드가 피드보다 커지면 브라우저가 스냅 위치를 다시 골라 윗 카드가 걸쳐 보이고 현재 카드 아래가 잘리기 때문이다(2026-09-28 모바일에서 재현). 피드 높이가 바뀌면 보던 카드 위치로 다시 맞춘다. 피드 높이는 정수로 내리고 카드 사이에 테두리를 두지 않는다. 높이가 소수점이면 답을 열 때 스냅이 1px 미만 어긋나 윗 카드 테두리가 맨 위에 비쳤다. 키보드는 ↑↓, PageUp/PageDown, j/k로 넘긴다.
