## 반영 내용

25개 국가·역사 체제를 점검했다. 역사 사건 16개, 인물 21명과 상세 절 21개, 경제 용어 19개를 추가하고 기존 경제 용어 4개의 본문을 보강했다. 용어–인물·사건 및 사건–인물 연결 94개를 추가했다. 기존 인물·사건·상세 절은 수정하지 않았다.

## 근거와 편집 판단

- 역사·제도는 미 의회도서관 국가연구, 외교문서, 학술·연구기관 자료와 당대 문헌을 대조했다. 경제 통계에는 세계은행·IMF의 보고연도와 측정 대상을 적었다. 인물의 기초 사실에는 사전·부고를 함께 사용했다. 개별 URL과 인물 사실별 근거 위치는 콘텐츠 배치 및 공개 상세 페이지에 보존했다.
- 중국의 약 8억 명 빈곤 감소는 2022년 보고서의 당시 국제빈곤선 기준이다. 몽골의 생산국민소득은 현대 GDP와 구별했다. 모잠비크의 회복률은 전쟁 종식 효과를 포함하며 단일 정책의 인과 효과로 제시하지 않았다.
- 콩고인민공화국은 `republic-of-congo`에 연결했다. `congo`는 이 저장소에서 콩고민주공화국을 뜻한다. 남예멘은 기존 `yemen` 국가 허브를 사용하고 역사적 국가명과 현대 지도와의 차이를 설명했다.
- 캄보디아의 1975~1979년 체제와 이후 재건 체제를 구분했다. 베냉의 소글로와 마다가스카르의 라치만드라바는 사회주의 정권의 창건자로 분류하지 않았다.
- 폴 포트와 시아드 바레는 출생연도가 출처마다 달라 사망연도만 확정했다. 멩기스투의 생몰연대는 이번 보강에서 입력하지 않았다. 승인 대기 제안은 발생하지 않았다.
- 지도 표식은 Natural Earth populated places의 도시 좌표다. 사건이 발생한 도시의 개략적 위치이며 특정 건물의 정확한 좌표로 표시하지 않는다.

## 저장과 검증

- 실행 도구: `scripts/apply-socialist-state-content.js`; 자료: `scripts/content/socialist-states-20260908.json`. 인물·절은 `submitPersonEdit` → Admin store 경로만 사용했다. 인물 테이블에 직접 INSERT하지 않았다.
- 배치는 단일 트랜잭션이다. 기존 용어는 본문·출처만 보완하며 기존 값이 바뀌면 거부한다. 신규 ID가 이미 존재하면 동일 내용인지 확인한다. 관계는 기존 행을 덮어쓰지 않는다.
- 독립 PostgreSQL 17 컨테이너 `commulingo-content-test`, DB `commulingo_integrity_test`에서 검증했다. 운영 스키마와 사전 데이터만 복사했으며 학습진도와 사용자 테이블 데이터는 제외했다.
- `scripts/test-socialist-state-content-db.js`: 후반 FK 오류 시 전체 롤백, 재실행 추가 변경 0건, 동시 편집 거부·보존, 기존 인물·사건·절 원문 보존, 25개 국가의 핵심 항목 존재를 검증했다. `COMMULINGO_ISOLATED_TEST=1`, 명시적 테스트 연결, `CONTENT_BASELINE`으로 변경 전 조회 JSON이 필요하다.
- 인물 카드·원어 표기·부칭·이름 순서 검사 통과. 전체 사건 93개의 국가 코드·지도 표식 검사 통과. 계보도 8개의 형식 검사와 신규 노드 50개의 실제 참조·한영 SVG 렌더링을 확인했다.
- `npm test` 전체 통과. 운영 공개 상세·국가·계보도 88개 경로가 HTTP 200을 반환했다. Playwright로 계보도 3개의 한영 화면, 1440px·390px, 다크·라이트 테마, 노드 이동과 대표 인물·사건·용어·국가 페이지를 확인했다. 모바일은 기존 정책대로 전체 도표를 화면 폭에 맞춘다. 가장자리에서 잘리는 중복 화살표 설명은 정리했다.
- 외부 공개 도메인의 계보도 메뉴도 브라우저에서 HTTP 200과 새 링크 3개를 확인했다. 일반 Python HTTP 요청은 403을 받아 브라우저로 검증했다. 테스트 DB 컨테이너는 검증 후 제거했다.
- 기존 사건–인물 감사 경고 39건은 원래 데이터에도 존재했다. 신규 관계에는 미분류 또는 메모 없는 피해자 연결을 추가하지 않았다.

## 적용과 복구

운영 반영 직전 백업: `/tmp/commulingo-socialist-20260908/pre-apply-backup.sql`. 변경 전 조회, 테스트 로그, 적용 결과, 브라우저 검증 자료는 같은 작업 디렉터리에 보관했다. 운영 DB 적용 후 사전 스냅샷을 갱신했고 계보도 파일은 grass 소유로 원자적으로 게시했다. 운영 컨테이너의 재시작·재생성은 하지 않았다.

이 문서와 배치 JSON은 2026-09-08 적용 기록이다. 2026-09-13 현재 16개 사건의 한영 본문은 후속 심화 편집으로 더 길어졌으므로, 배치의 사건 본문을 현재 정본으로 다시 적용해서는 안 된다. 스크립트의 충돌 차단을 유지하고 현재 DB와 대상 필드를 먼저 대조한다.

운영 반영 명령은 컨테이너에서 `APP_ROOT=/app node /tmp/apply-socialist-state-content.js /tmp/socialist-states-20260908.json --apply --production`이었다. 호스트의 검증된 스크립트·배치 파일을 컨테이너 `/tmp`로 복사해 실행했다.

복구가 필요하면 전체 DB를 과거 상태로 덮어쓰지 않는다. 배치에 기록된 대상 ID와 원래 값을 비교해 해당 사건·용어·관계만 복구하고, 신규 인물·절의 취소는 Admin 편집·검토 경로를 따른다. 이후 추가된 편집·연결을 확인한 뒤 처리한다. 계보도는 해당 세 파일만 제거하면 메뉴에서 내려간다.
