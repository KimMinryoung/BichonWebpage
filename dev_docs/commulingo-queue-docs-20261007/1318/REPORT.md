## 문서 특정
큐 제목 「국경방비요령(Border Defense Guide)」은 정식 제목이 아니다. 문서는 「滿「ソ」國境紛争處理要綱」(만·소 국경분쟁 처리 요강), 관동군 작전명령(關作命) 제1488호 별책, 1939-04-25 발령(사령관 우에다 겐키치), 쓰지 마사노부 기초. 방침 1항 + 요령 7항(제2~8항) + 비고. 원어 일본어. 큐 reason이 인용한 「소련 영토에 들어가거나 소련군을 만주 영내로 유인」은 제3항(「一時的ニ「ソ」領ニ進入シ又ハ「ソ」兵ヲ滿領内ニ誘致、滯留セシムルコトヲ得」)과 일치한다.

## 상위 에이전트 확인점
- 사건 카드·인물 카드가 이 문서를 「국경방비요령」/「Border Defense Guide」/「국경 방침서」로 부른다. 정식 제목은 「만·소 국경분쟁 처리 요강」. 카드 문구를 정식 제목으로 고칠지(소유자 결정 「카드는 번역에 맞춘다」 적용 대상), 아니면 「국경방비요령」을 별칭으로 유지할지. 현재 별칭에 「국경방비요령」「Border Defense Guide」를 넣어 두었다.
- 사건 카드 「4월 25일 채택」 — 문서 자체에는 날짜가 없고, 날짜는 명령 제1488호 발령일(통설). 
- 사건 카드 인용 「필요시 소련 영토에 들어가거나 소련군을 만주 영토 안으로 유인해 싸워도 된다」: 번역은 「이 목적을 달성하기 위하여 일시적으로 소련 영내에 진입하거나, 소련군을 만주 영내로 끌어들여 머물게 할 수 있다」. 맞출 것.
- 우에다 겐키치 인물 카드가 없다.
