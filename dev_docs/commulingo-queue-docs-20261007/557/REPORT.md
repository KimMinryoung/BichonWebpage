## 상위 에이전트 확인점
- 사건 카드(prague-spring)는 이 문서를 「위기 발전의 교훈」으로 부르고 「1970년 12월 11일 … 승인」이라 적는다 — 별칭에 「위기 발전의 교훈」을 넣었고 manifest date를 1970-12-11로 했다. 전원회의는 10~11일.
- 카드는 「바실 빌랴크가 주도해 기초」라고 쓰는데 문서 자체에는 기초자 표시가 없다(문서는 집단 저작으로 제시됨). 카드 서술은 연구 문헌 근거여야 함.
- 카드의 「상임간부회」·「체르나 협상」과 이 번역의 「간부회」·「치에르나나트티수」 표기가 다르다. 통일 여부 결정.
- 문서 안의 반유대주의적 「시오니즘」 낙인(크리겔·골트슈튀커 등)과 하벨 등에 대한 「서방 정보기관 첩자」 비난은 원문 그대로 옮겼다. 사료 성격은 엮은이 주에서 「공식 언어의 기준」으로만 밝혔다 — 별도 경고가 필요한지 소유자 판단.
- 분량(원문 11만여 자)이 BRIEF의 5만 자 기준을 넘는다. 소유자 결정 A로 완역함.
