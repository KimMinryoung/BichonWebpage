## 문서 특정
이탈리아 정부가 그리스 정부에 보낸 「comunicazione」(통첩). 1940년 10월 28일 03시 아테네 주재 이탈리아 공사 에마누엘레 그라치가 메탁사스에게 전달. 통첩문은 외무장관 치아노가 10월 26일 그라치에게 보낸 전보(T. 33759-62, 분할 번호 319~322) 안에 실려 있고, 319 부분이 전달 방법 훈령(새벽 3시 예고 없이 전달, 세 시간 뒤 6시에 이탈리아군 진입을 구두로 통보)이다. 짧은 문서이고 훈령이 통첩의 성격(기한 없는 요구 + 3시간 뒤 무조건 진입)을 보여 주므로 전보 전체(문서 789)를 옮겼다.

원문 언어: 이탈리아어. DDI에 실린 것은 로마에서 작성·암호화한 이탈리아 정부의 문안이다. 실제로 메탁사스에게 건넨 사본이 이탈리아어였는지 프랑스어 번역본이었는지는 확인하지 못했다(메탁사스와 그라치의 대화는 프랑스어였다). 그리스 백서(1940/1942)에 실린 판본과 대조하지 못함.

## 표기 결정
- 갈레아초 치아노, 이오아니스 메탁사스, 베니토 무솔리니(사전 카드), 에마누엘레 그라치(사건 카드 표기). 루이지 몬디니.
- Ministro ad Atene → 「아테네 주재 공사」(이탈리아의 아테네 공관은 공사관). Ministro degli Esteri → 외무장관.
- comunicazione → 「통첩」(문서 자체는 ultimatum이라는 말을 쓰지 않음; 제목에서 「최후통첩」 대신 「통첩」, 별칭에 「최후통첩」).
- Ciamuria → 「차메리아」(그리스 북서부 테스프로티아 일대, 알바니아어 Çamëria). Arcipelago greco → 「그리스 다도해」. garanzia britannica → 「영국의 보장」(1939년 4월 영국·프랑스의 그리스 보장).
