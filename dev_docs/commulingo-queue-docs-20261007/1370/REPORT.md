## 문서 특정
독일 육군 총사령부(OKH, 총사령관 브라우히치·참모총장 할더) 「Aufmarschanweisung Gelb」의 네 번째 판(Neufassung), 1940년 2월 24일. 중점을 B집단군에서 A집단군(룬트슈테트)으로 옮겨 아르덴을 지나 세당–디낭 사이 뫼즈 강 돌파를 주공으로 삼은 판이며, 뒤에 「Sichelschnitt」라 불린 작전의 실제 명령 문서다. 원어 **독일어**. 국가 기관의 공식 명령이라 저작권 문제는 없음.
