- 상태: **skip** (사유: 저작권 — 공식 회의록이 아닌 체르냐예프 개인 메모, 러시아어 원문은 저작권 있는 편찬서에만 있음)
- 큐: event `new-thinking-diplomacy`
- 산출: 이 REPORT만

## 문서 특정
- 큐 reason이 가리키는 「National Security Archive가 공개한 회의 기록」은 NSA 브리핑북 「The Last Superpower Summits」(2017)·EBB 238(2007)의 문서 7 「Soviet Politburo meeting, February 26, 1987」이다.
  https://nsarchive.gwu.edu/document/22554-document-07-soviet-politburo-meeting-february-26
- 실물(PDF 3쪽)은 **영어 번역**(Svetlana Savranskaya 번역)뿐이다. 출처 표기는 「the Archive of the Gorbachev Foundation, Moscow」. NSA가 이 시기 정치국 기록에 다는 출처(Gorbachev Foundation, Fond 2, opis 1)와 내용 형식(「고르바초프. …」「리가초프는 자기 입장을 고수한다」 같은 요약 서술, 말줄임)으로 보아 **아나톨리 체르냐예프의 회의 메모 발췌**다. 정식 속기록·작업 기록(рабочая запись)이 아니다.
- EBB 238의 `russian/Final1987-02-26 Politburo.pdf` 경로도 받아 보았으나 내용은 같은 영어 번역이다(러시아어 원문 아님).

## 원문 확보 시도
- 러시아어 원문(체르냐예프 메모)은 『В Политбюро ЦК КПСС… По записям Анатолия Черняева, Вадима Медведева, Георгия Шахназарова (1985–1991)』(М.: Альпина Бизнес Букс, 2006; 2-е изд. 2008)에 실린 것으로 알려져 있다. 온라인 공개본은 찾지 못했다.
- 공식 작업 기록(Рабочая запись заседания Политбюро 26.02.1987): NSA 러시아어 자료실(「Архив Перестройки — Политбюро」「Шедевры истории 1985–1988」), Bukovsky Archive 1987년 목록(2월 항목에 2월 26일 정치국 없음), 웹 검색 모두에서 찾지 못했다.

## 저작권 판단
- 체르냐예프(1921–2017)의 개인 메모이고, 러시아어본은 2006년 저작권 편찬서에 수록. BRIEF 기준 4(개인 수첩·메모, 사후 70년 미경과) → skip.
- 영어 번역만 공개돼 있어 기준 2(중역 금지)에도 걸린다.

## 한국어 번역본 확인
- 원문을 낼 수 없어 깊게 확인하지 않았다. 「1987년 2월 26일 정치국 패키지」류 검색에서 한국어 번역은 보이지 않았다.

## 상위 에이전트 확인점

- 참고: 사건 카드 new-thinking-diplomacy 본문의 2월 26일 서술(리가초프·소콜로프 포함 전원 찬성)은 NSA 해설 요약과 같다. 메모 자체에서 소콜로프는 「프랑스·영국 미사일을 상기시킨다」로만 나온다.
