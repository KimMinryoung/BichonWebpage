## 처리
- 같은 헌법(알바니아 인민공화국 헌장, 1946년 3월 14일)의 전문 완역을 1882에서 냈다: `../1882/albania-constitution-1946.html`(doc id `albania-constitution-1946`). 일부 조문만 따로 내지 않는다(발췌 번역 금지 원칙). resolved_id는 `albania-constitution-1946`으로 하면 된다.

## 조 번호 주의
- 요청의 조 번호(제7·8·11·12조)와 내용은 **1950년 7월 5일 개정 헌법**의 번호다(1950년 헌법 Neni 7 공동재산, 8 경제계획, 11 사유재산, 12 토지 — 위키문헌 sq 「Kushtetuta e Republikës Popullore të Shqipërisë」로 확인).
- 1946년 헌법에서 같은 내용은 **제5조**(생산수단의 세 형태·인민의 공동재산·대외무역 통제), **제6조**(일반 경제계획과 사적 부문 통제), **제9조**(사유재산 보장과 제한·수용·국유화, 독점 금지), **제10조**(토지는 경작자의 것, 대토지 사유 금지, 토지 소유 상한)다. 1946년 제7조는 공동재산의 관리, 제8조는 협동조합 지원, 제11조는 근로 대중 단결 지원과 피고용인 보호, 제12조는 법 앞의 평등이다.
- 사건 카드 본문도 같은 혼동이 있다(1882 REPORT 「상위 에이전트 확인점」).
