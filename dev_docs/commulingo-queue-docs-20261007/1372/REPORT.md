## 문서 특정
- 1941년 9월 26(~27)일 크루파니 부근 스톨리체(광산 건물)에서 열린 파르티잔 군사·정치 회의는 결의문을 공표하지 않았다. 문서집·연구서가 「스톨리체 회의의 결정」(편제: 중대-대대-분견대, 참모부 구성, 최고사령부·지역 총사령부 개편, 표지·경례)을 말할 때 드는 당대 1차 근거는 『최고사령부 회보』(Bilten Vrhovnog štaba NOPOJ) 제7·8호(1941-10-01, 우지체)다(sh.wikipedia 「Savjetovanje u Stolicama」도 「Bilten Vrhovnog štaba NOPOJ, br. 7 i 8」를 출처로 듦).
- 그 호에서 회의에 해당하는 글은 두 편: (A) 권두 기사 「Савјетовање претставника штабова и команданата НОП одреда Југославије」(서명 없음, 최고사령부 기관지 사설), (B) 「Наредбе」 I–III(「За Врховни штаб … Тито」 서명; 모자 표지, 깃발, 경례 통일). 이 둘을 완역했다. 같은 호의 전선 소식·표창은 회의와 무관해 뺐다(HTML 일러두기에 명시).
- 큐 reason과의 대응: 「분견대 표준화」 → (A)의 연결·규율 지적과 (B)의 표지·깃발·경례 통일(중대-대대 편제 수치는 이 호에 없음). 「해방구 확대」 → (A)의 지역별 상황. 「미하일로비치와의 협상 지속」 → (A)의 「중립 체트니크 집단과의 충돌 회피」 노선(미하일로비치 이름·협상은 직접 나오지 않음).
- 원어: 세르보크로아트어(키릴, 에카비안·이예카비안 혼용).
