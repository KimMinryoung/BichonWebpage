## 문서 특정
1961년 4월 16일 아바나 23번가와 12번가 모퉁이(콜론 묘지 앞)에서 열린 4월 15일 공습 희생자 장례식에서 혁명정부 총리 피델 카스트로가 한 연설. 「¡y que hayamos hecho una Revolución socialista en las propias narices de Estados Unidos!」(source.es.txt의 106번 블록 — 이하 블록 번호는 source.es.txt 기준, 1·2번은 제목)가 큐 reason이 인용하는 구절이다. 원어 스페인어.

## 상위 에이전트 확인 사항
1. 81번째 블록(미로 카르도나와 플라야히론)의 덧붙임 여부 — 『Obra Revolucionaria』 원본과 대조할 수 있으면 확인.
2. 사건 카드 본문의 「희생자 7명」은 연설(「영웅적인 목숨 일곱」)과 맞는다. 사건 카드가 쓰는 비행장 이름 「시우다드리베르타드」와 연설의 「캄포리베르타드」가 같은 곳임을 엮은이 주에 병기했다.
3. 사건 카드 본문은 이 연설을 「'우리는 미국의 바로 코앞에서 사회주의 혁명을 이루어냈다'」로 인용한다. 번역문은 「우리가 바로 미국의 코앞에서 사회주의 혁명을 이루었다」 — 카드 인용을 번역에 맞출지 판단.
4. 사건 카드 본문의 「연설은 무기를 든 이가 누구인지 물으며(용병인가, 노동자의 손인가)」는 109번 블록(「누가 무기를 쥐고 있습니까?」)과 맞는다.
5. terms는 해당 용어 카드(중앙정보국·피그스만 등)가 없어 비움.
