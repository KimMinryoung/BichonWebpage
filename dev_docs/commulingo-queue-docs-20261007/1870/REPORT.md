## 저본
- 중국어 위키문헌 「中國人民政治協商會議共同綱領」(『中央人民政府法令彙編（一九四九——一九五〇）』 44~53쪽 스캔을 전사, 위키문헌 교정 단계 75%), https://zh.wikisource.org/wiki/中國人民政治協商會議共同綱領 (2026-10-07 접근, API로 받음).

## 한국어 번역본 확인 (꼼꼼히 — 결과: 온라인·목록상 없음, 인쇄 자료집 일부는 미확인)
- 웹: 「"중국인민정치협상회의 공동강령" 전문 번역」, 「공동강령 1949 번역 자료집 중국 헌법」, 「"공동강령" 중국 1949 자료집 수록 번역 국회도서관 OR 법제처 OR 아세아문제연구소」, 본문 문구 검색 「"중화인민공화국은 신민주주의" 공동강령 제1조」 — 한국어 번역 전문 없음.
- 한국어 위키문헌: 「공동강령」「중국인민정치협상회의」 검색 — 없음(현행 「중화인민공화국헌법」, 「중화민국헌법」 번역만 있음).
- 법제처 세계법제정보센터: 현행 중화인민공화국 헌법만.
- 국립중앙도서관 검색 「공동강령」: 김정계 「〈공동강령〉 시기 중국의 정치·행정체계」(창원대 인문과학연구소, 1998, 논문) 등 연구 논문만. 단행 번역본 없음.
- 미확인: 1950년 전후 북조선에서 나온 번역(정치협상회의 문헌집류)이나 국내 중국 현대사 사료집의 부록 수록 여부는 원문 열람 없이 확인하지 못했다. 상위 에이전트가 RISS·국회도서관 소장 「중국 헌법 자료집」류를 한 번 더 보기를 권한다.

## 표기·용어
- 人民民主專政 → 인민민주독재, 民主統一戰綫 → 민주통일전선, 小資產階級/民族資產階級 → 소자산계급/민족자산계급, 合作社 → 합작사(공급판매합작사 등), 軍事管制委員會 → 군사관제위원회, 各界人民代表會議 → 각계인민대표회의, 人民革命軍事委員會 → 인민혁명군사위원회, 民主集中制 → 민주집중제, 惡霸 → 악패, 耕者有其田 → 「경작자가 자기 땅을 가지는 것」, 公私兼顧·勞資兩利·城鄉互助·內外交流 → 풀어 옮김.

## 상위 에이전트 확인점
- 사건 카드 「신민주주의는 노동자·농민뿐 아니라 소자산계층과 민족자본가를 포함하는 연합」: 문서 용어는 「소자산계급」「민족자산계급」. 카드 표현을 맞출지 검토.
- 큐 reason의 「mixed-ownership economy (state, cooperative, private, state-capitalist)」: 문서 제26조는 다섯 성분(개체 경제 포함). 카드에 넷으로 쓰였으면 다섯으로.
- 별칭 맨 「공동강령」은 다른 「공동강령」(예: 다른 나라 정당 연합의 공동강령)과 겹칠 수 있다 — 사이트에 다른 공동강령 문헌·용어가 있으면 검색 전용으로.
