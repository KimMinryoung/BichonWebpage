## 상위 에이전트 확인 사항
1. 사건 카드 `angolan-independence-1975-1977` 본문의 인용 「"사보퉁이, 기생충, 기회주의자들을 끝장내기 위해 민주혁명독재를 적용할 것"」은 원문(「Apliquemos a Ditadura Democrática Revolucionária, para acabar de vez com os sabotadores, com os parasitas, com os especuladores」)과 다르다: 「기회주의자」가 아니라 「투기꾼」(especuladores), 「사보퉁이」는 오타, 영어판의 「with opportunists」도 틀림. 번역은 「사보타주꾼, 기생충, 투기꾼을 영원히 끝장내기 위해 혁명적 민주독재를 적용하자」. 카드 수정 검토.
2. 사건 카드의 알베스 문건 제목 「나를 위한 13개 논제」 — 원문은 「13 teses em minha defesa」, 번역은 「나를 변호하는 13개 테제」. 맞출지 판단.
3. 사건 카드 마지막 절의 「8여단의 무장 행동」 — 이 문서는 정찰대대가 제9여단 소속이라고 쓴다(「Batalhão de Reconhecimento da 9.ª Brigada」). 카드 앞 절도 「제9기갑여단」이라 해 카드 안에서 서로 어긋남.
4. 옮긴이 주 8(코스타 마르틴스 = 포르투갈 전 노동장관 주제 다 코스타 마르틴스)과 주 6(DIP 풀이)은 「~로 보인다」로 단서를 달았다. 확인되면 단정형으로.
5. people에 바칼로프, 몬스트루 이모르탈, 사이디 밍가스, 오남부에 등은 카드가 없어 넣지 않았다.
6. 별칭 「정치국 보고 책자」는 일반어에 가까워 검색 전용 검토.
