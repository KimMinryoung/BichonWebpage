# 참고문헌 자동링크 정리 — 2026-09-13

사용자 요청: 참고문헌의 잘못된 자동링크를 해제하고 ‘탈레’ 같은 모호한 별칭은 자동링크 대상에서 제외한다. 기존 링크 엔진과 DB 제외 목록·문헌별 noAutoLink만 사용했으며 코드 배포나 컨테이너 재시작은 하지 않았다.

- 전체 공개 참고문헌의 렌더링 결과에서 링크 5,931개를 수집했다. 짧은 별칭, 다른 단어의 일부, 문헌보다 뒤 시대의 인물·제도를 중심으로 실제 문맥을 검토했다. 전 링크의 의미적 정확성을 보증하는 검사는 아니다.
- 전역 인명 별칭 제외 5개: 탈레, 키우, 시킨, 포트, 베크. 예브게니 탈레·키우 삼판 등 전체 이름은 자동링크가 유지된다.
- 문구 제외 3개: 외환 거래상 리트빈, 슈미트, 리코프의 부위원장, 군사위원회. 다른 곳의 실제 리트빈·슈미트·정치위원 링크는 유지한다. 정확한 구분과 종류는 exclusions.json과 global-rules.sql을 따른다.
- 29개 문헌에 68개의 noAutoLink 표현을 추가했다. 프랑스 법의 제58조, 코츠 회사, 로도스 섬, 제헌의회·집단화·동반자 등의 문맥을 기록했다. 소설의 의도적인 인물 대응은 유지했다.
- reviewed-errors.json은 실제 렌더링에서 확인한 99개 오연결과 문맥이다. ‘탈레’는 처음 확인 후 먼저 제외했으므로 이 후속 수집 기록에는 포함되지 않는다. 원래 발견 문구는 구주의 ‘탈레랑’과 스페인 내전 저작의 ‘탈레스니크’다.
- 기존 문헌 통합 스크립트의 재실행으로 제외어가 되돌아가지 않도록 준비 manifest도 동기화했다.

검증: 68개 문헌별 제외와 8개 전역 규칙을 실제 링크 엔진으로 확인했다. 레닌·예브게니 탈레·키우 삼판의 전체 이름 링크가 유지됨을 확인했다. 대표 문헌 한 곳에서 본문 보존·탈레랑/동반자 오연결 제거·정상 인물 링크를 브라우저로 확인했다. 영향 문헌의 한국어·영어 및 분할 페이지 캐시를 갱신했다. 화면 조합별 반복 검사나 전체 테스트 재실행은 하지 않았다.
