# 인물 역할 분류 재설계안 — 기능·활동 × 국가·세력

2026-09-22 승인된 계획과 구현 기록. 아래 전환 상태는 전체 이관 후보와 확정 배정을 구분한다.

## 문제와 권고

현재 인물 2,390명의 대표 역할은 소련 기관 16개 또는 역할 범주 19개 중 하나다. 이 목록에는 기능(외교·보안), 소속(중공·사회주의권), 정치적 위치(반혁명·반체제), 직업(작가·연구자)이 섞여 있다. 같은 일을 해도 소련 인물은 기관, 중국 인물은 중국 전용 범주, 다른 나라 인물은 포괄적인 진영 범주로 들어간다.

대표 역할을 **기능·활동**으로 통일하고, 그 활동을 수행한 **국가·세력·조직**을 두 번째 축으로 둔다. 기존 기관은 별도의 기관·직위·재임 연표로 보존한다. 국적과 시대 그룹은 기존 필드를 유지한다.

핵심은 기능과 소속을 각각 독립된 태그 목록으로 저장하지 않는 것이다. 사람의 활동 하나에 기능·소속·기간·근거를 함께 연결해야 서로 다른 시기의 경력이 잘못 조합되지 않는다.

대표 기능은 1개다. 추가 활동은 출처로 확인되는 중요한 경력에 한해 연결하며, 인물 카드에는 대표 기능만 기본 노출한다. 모든 짧은 경력을 분류 항목으로 늘리지 않는다.

기존의 개혁파·반체제·반혁명은 기능이 아니다. 구체적인 기능으로 다시 판단하고, 정치적 입장·사건에서의 역할은 근거와 시점을 갖춘 서술 또는 기존 사건 관계에 보존한다. 단순히 삭제하거나 다른 이름으로 일괄 치환하지 않는다.

## 2차 분류: 활동 당시의 소속

- 국적을 복사하지 않는다. 실제 복무·고용·당적·조직 활동을 근거로 연결한다.
- 조직을 특정할 수 있으면 조직에 연결하고, 그 조직이 속한 국가·세력은 조직 관계에서 파생한다. 국가·조직을 중복 입력해 서로 모순되게 만들지 않는다.
- 국가·정권·정당·군대·국제조직은 종류를 구분한다. `중국` 아래의 중공과 국민당을 구별하고, 러시아 제국·소련·러시아 연방을 하나의 정치적 소속으로 합치지 않는다.
- 일당제 현실 사회주의 체제의 구성원으로 수행한 활동은 **국가 이름과 국가 ID**에 연결한다. 집권당 지도·간부 활동과 정부·국가기관·군·보안기관 복무를 포함하며 비당원도 같은 원칙을 따른다. `kind=state`이고 관계는 `service`(실제 고용이면 `employment`)이며 `membership`은 쓰기 검증에서 거부한다. 반대파 활동·독립 연구·국적만으로 국가 소속을 부여하지 않는다.
- 건국 전 혁명 활동, 집권기 밖 정당 활동, 체제 반대파 활동은 확인된 정당·세력에 남긴다. 같은 인물의 이전 국가 복무와 나중의 반대파 활동은 별개다. 정당 항목의 `governingState`는 대응 국가와 적용 기간을 적고, Jev criteria도 같은 경계를 명시한다. 소련·중화인민공화국·동독·북한의 국가 ID를 복구했으며 옛 국가→정당 redirect는 제거했다. 정당 ID는 건국 전 활동 때문에 유지한다.
- 기존 활동 이관은 근거 발췌를 로컬 검토하고 공통 편집 서비스를 사용한다. 검토 기록은 `scripts/content/socialist-state-affiliations-20260927.json`이다. 시기가 명시된 정당 경력이 건국 전후를 가로지르면 활동을 나누고 대표 활동은 국가 시기로 둔다. 실제 국가기관 복무는 체제 전환 뒤에도 같은 국가에 이어질 수 있다. 옛 역할의 표시·검색 매핑은 국가를 사용하되 `legacyBeforeState`와 사망년으로 건국 전 사망자를 정당에 남긴다.
- 프랑스 혁명기(1789–1830)는 진영이 아니라 실제 조직을 쓴다: 클럽·파벌(자코뱅·코르들리에·산악파·지롱드·푀양·앙라제·평등주의자 결사), 파리 코뮌(1789–1795), 그리고 날짜에 맞는 체제(부르봉 왕정 ~1792·1814–1830, 제1공화국 1792–1799, 통령정부·제1제국 1799–1815). `프랑스 혁명 진영`은 조직을 특정할 수 없을 때만, `프랑스 국가기관`은 1830년 이후에만 쓴다. 2026-09-26 재판정은 `scripts/content/french-revolution-activities-20260926.json`.
- 존속 기간이 분명한 소속은 카탈로그에 `periods`([[시작|null, 끝|null], ...])를 둔다. 쓰기 검증은 활동 연도가 기간 밖(앞뒤 1년 여유)이면 거부하고, 분류기는 선택된 근거 발췌의 연도와 겹치는 소속만 Jev에 제시한다. 기간이 없는 항목(존속이 긴 국가 등)은 항상 제시한다.
- 조직의 상위 소속이 바뀌는 경우에는 관계에도 시기를 기록한다. 날짜를 모르면 추정 연도를 만들어 넣지 않는다.
- 독립 연구자·작가에게 정치적 소속을 강제하지 않는다. 확인된 활동 소속 없음과 미검토를 구별한다. 연구 대상인 소련·중국을 소속으로 삼지 않는다.
- 여러 국가·세력을 거친 인물은 각각의 활동과 기간을 연결한다. 국적이 외국이라는 이유로 실제 소련 기관 경력을 막지 않는다.

UI에는 첫 단계에서 국가·세력 수준을, 필요한 경우 그 안의 조직을 펼쳐 보여준다. 모든 기관을 평평한 필터 목록에 나열하지 않는다.

## 기관과 연표의 위치

`commulingo_offices`와 기관별 연표는 폐기하지 않는다. 기관은 기능 분류 자체가 아니라 구체적인 경력의 대상이 된다.

- 현재 기관 페이지와 재임자 연표 URL은 유지한다.
- 한 기관에 여러 기능이 있을 수 있고, 같은 기능을 여러 기관에서 수행할 수 있다.
- 대표 기능을 바꿔도 연표의 재임자 명단이 늘거나 줄어들지 않게 한다. 단순 역할 배정을 재임 사실로 취급하지 않는다.
- 기존 기관 중 `과학·원자력·우주 개발`처럼 여러 조직을 묶은 항목은 단일 법적 기관으로 간주하지 않고 기관 계열·주제 연표로 표시한다.
- 중국 기관 연표 확장은 나중에 별도 출처·재임 자료가 준비될 때 추가할 수 있다. 이번 분류 이관에 재임 이력을 임의 생성하지 않는다.

## 화면과 아이콘

인물 목록에서 `기능·활동 → 국가·세력 → 필요시 조직` 순으로 좁힌다. 기능을 고르지 않고 국가·세력부터 고르는 것도 허용한다. 같은 활동 행에 두 조건이 함께 맞는 사람만 결과에 포함한다.

카드는 **기능 아이콘 + 대표 기능 + 활동 소속**을 보여준다. 정치 지도는 공통 기능 아이콘을 쓰고, 중공 특색은 소속 배지의 낫·망치로 표현한다. 공용 `hammer-sickle` SVG를 재사용할 수 있다. 기능 아이콘을 국가마다 다르게 만들지 않는다. 작은 화면에서 기호가 과밀해지면 기능 아이콘과 소속 텍스트를 기본으로 하고 조직 배지는 상세에서 보여준다.

소속의 낫·망치는 중공 당장 설명에 맞춘다: https://19th.cpcnews.cn/english/n100/2017/0929/c176-471.html

시대별 선반은 탐색 방식으로 유지하고 기능 필터와 결합한다. 시대 그룹까지 동시에 재설계하지 않는다.

## 데이터·API 계약

소련의 국가 활동은 `state-soviet` / `kind=state` / **소련 · Soviet Union**으로 저장·표시한다. `soviet-party`는 건국 전 볼셰비키와 확인된 정당 활동을 위한 별도 항목이다. 중화인민공화국은 `china-prc`, 동독은 `state-east-germany`, 북한은 `state-north-korea`를 사용한다.

최종 명칭은 구현 시 기존 국가·기관 저장 구조와 대조해 확정한다.

- 기능 레지스트리: id, 한·영 이름, 설명, 아이콘, 포함·제외 기준.
- 활동 소속 레지스트리: id, 종류, 한·영 이름, 시기, 기존 국가·기관과의 관계. 기존 국가 자료는 재사용한다.
- 인물 활동: personId, functionId, affiliationId(없을 수 있음), 소속 확인 상태, 관계 종류, 기간, primary, 근거. 기관·직위는 확인된 경우 연결한다.

### 기관 계열 연결과 반대파 소속 (2026-09-30)

- 활동에 선택 필드 `officeId`를 두었다. 값은 `commulingo_offices`의 기관 계열 id이고, 그 활동의 소속이 `state-soviet`·`soviet-party`·`comintern`일 때만 허용한다. 존재 여부는 Admin 스토어가 DB의 기관 목록으로 검사한다. 활동이 저장되지 않은 인물의 호환 표시 행도 구 role의 `office_id`를 그대로 싣는다. 구 role에만 있던 기관 정보가 이제 활동 행에도 붙는다.
- 표시와 조회: 인물 상세의 활동 줄에 기관 계열 링크가 붙는다. 기관은 소속이 아니므로 소속 카탈로그에 넣지 않는다. 기관 페이지는 `?affiliation=state-soviet&office=<id>`로 연결한다.
- 활동 페이지(2026-09-30 재설계): 필터는 드롭다운이 아니라 인원수가 붙은 링크 칩이다. 기능 18개는 한 줄로 모두 보인다. 소속은 인원이 많은 8개와 '나라별 전체 소속' 패널(검색창, 나라 이름으로도 일치)로 고른다. 기관 계열은 소련·소련공산당·코민테른을 고른 뒤에만 나온다. 모든 칩이 결과 URL이라 JS 없이도 동작한다. JS가 있으면 `#activity-browser`만 갈아 끼워 새로고침과 스크롤 점프가 없고, 뒤로 가기도 같은 방식으로 복원한다. 소속을 바꾸면 기관 계열은 풀리므로, 소속 칩의 인원수는 기관 조건을 빼고 센다. 모바일에서는 facet마다 가로 스크롤 한 줄이다. 이전의 드롭다운 폼은 선택지가 다른 조건에 따라 바뀌어 적용을 누르기 전까지 맞지 않았고, 소속 약 200개를 한 목록에서 찾게 했다.
- 이미 활동이 저장된 인물은 활동의 기능이 기관과 맞을 때만 `officeId`를 옮겼다(크릴렌코 군사→국방, 포툠킨·비신스키 외교, 유리 즈다노프 선전, 아쿨로프 등 보안 3명). 법조인을 `state-security`로 묶었던 경우처럼 구 기관이 잘못 대응된 행에는 옮기지 않았다.
- 카탈로그 v16에 구 `좌익반대파` 범주에 해당하는 조직을 추가했다. 소련공산당 하위(`parentId=soviet-party`, 따라서 소련공산당 필터에 포함)에는 좌익공산주의자(1918), 민주집중파(1919–1927), 노동자 반대파(1920–1922), 노동자 그룹(1922–1923), 좌익반대파(1923–1933, 연합반대파와 망명·지하 트로츠키주의 반대파 포함), 류틴 그룹(1932)을 넣었다. 별도 조직으로 크론시타트 임시혁명위원회(1921)와 미국 사회주의노동자당(1938–)을 넣었다. 구성원 24명의 활동은 위키백과 plain-text 발췌를 근거로 붙였다. 전시 재판의 혐의만 있는 경우는 인정하지 않았다: [편집 명세](../scripts/content/person-activity-edits-opposition-offices-20260930.json). 페트리첸코는 크론시타트를 대표 활동으로, 캐넌의 미확정 소속은 SWP로 확정했다.
- 편집 파일(`add`·`patch`)은 `scripts/build-person-activity-edits.js`로 현재 행과 revision을 읽어 `apply-person-activities.js` 명세로 만든다. patch는 저장된 활동 하나에만 맞아야 한다.

### 정치적 입장 모음 (2026-09-30, migration 213)

- 기능도 조직도 아닌 입장 범주 5개(제정·백색진영, 반혁명 세력, 좌익 반대파, 사회주의권 개혁 지도자, 반체제 인사)를 `commulingo_person_collections`·`commulingo_person_collection_members`로 옮겼다. 제목과 소개글이 있는 큐레이션 명단이고, 한 사람이 여러 모음에 들 수 있다. id는 범주 id 그대로라 `/commulingo/roles/<id>`가 계속 이 모음을 보여 준다. 인물 사전 첫 화면의 '정치적 입장별 모음'과 인물 상세의 '포함된 모음'에서 연결된다.

### 소련 기관 계열 인물 활동 저장 (2026-09-30)
