# CommuLingo 학습 활동 측정

구현: 2026-09-12. 새 학습 설계와 별개로 **현재 강좌·퀴즈 플레이어**의 조작을 측정한다. 페이지 조회, 고유 사람 수, 매일 재방문은 측정하지 않는다.

## 수집 범위

- 강좌: 문항 로딩 후 학습 시작, 답변 제출, 라운드 결과 화면 도달. 오답 재시도는 `retry` 모드로 분리한다.
- 퀴즈: 최초 답변 때 시작과 답변을 기록하고 결과 화면에서 완료한다. 페이지가 자동으로 문제를 불러오는 것만으로 시작을 기록하지 않는다.
- 연표 순서 맞히기: 채점 버튼을 누르면 한 번의 답변으로 기록한다. `correct`는 순서 전체가 맞았는지를 뜻한다.
- `completed`는 결과 화면까지 진행했다는 뜻이며 전부 정답이나 숙달을 뜻하지 않는다.
- 여러 장을 섞는 기존 복습, 인물 카드 읽기, 개념도·역사 선택형 콘텐츠, 사전 열람은 이번 집계 범위에 포함하지 않는다.

각 라운드는 새 무작위 ID를 가진다. 라운드 ID, 이벤트 ID, 콘텐츠 ID·버전, 언어, 모드, 단계 번호, 정오, 서버 수신 시각만 PostgreSQL `commulingo_learning_events`에 저장한다. 계정·IP·사용자 에이전트·답안 원문을 이 테이블에 저장하지 않는다. 서로 다른 라운드를 동일인으로 연결하지 않는다.

이벤트 ID와 `(run_id, event, step)` 두 제약으로 중복을 막는다. 답변·완료는 같은 콘텐츠·버전·언어·모드의 시작 기록이 있을 때만 저장한다. 전송 오류는 제한적으로 재시도하며 학습 진행을 막지 않는다. 페이지 종료·통신 장애·거부 설정에 따른 누락은 가능하다.

## 테스트·운영자 제외

클라이언트: `navigator.webdriver`, DNT, Global Privacy Control, 테스트 쿠키, 집계 거부 쿠키를 확인한다. 신뢰 가능한 브라우저 입력이 한 번도 없으면 기록하지 않는다.

서버: 개발 환경, 미리보기·비공개 호스트, 운영자 인증 세션, 명시적 테스트/거부 쿠키, `x-commulingo-test: 1`, 알려진 봇·자동화 도구 사용자 에이전트를 제외한다. 제외 응답은 204이며 저장하지 않는다. 공용 HTML 캐시에 운영자 상태를 넣지 않고 이벤트 요청 때 판정한다.

**운영자도 공개 사이트에서 로그아웃 상태라면 자동으로 식별할 수 없다.** 사용하는 각 브라우저에서 다음 주소를 한 번 열어 테스트 모드를 켠다.

- 켜기: `https://cyber-lenin.com/commulingo/book/capital-vol1?learning_test=1`
- 끄기: 같은 주소에서 `learning_test=0`

설정은 해당 브라우저의 사이트 쿠키에 1년간 유지한다. 쿠키 삭제·다른 브라우저 사용 시 다시 설정해야 한다. 자동화는 기본 `webdriver`를 유지하고, 이를 숨기는 도구라면 위 테스트 URL 또는 테스트 헤더를 사용한다. 일반 방문자는 학습 화면 아래 **앞으로 내 학습 활동 집계하지 않기**로 거부할 수 있다.

거부 설정은 그 브라우저에서 이후 이벤트 전송을 멈춘다. 이미 수신된 이벤트에는 방문자를 다시 식별할 값이 없으므로, 체크 시 과거 이벤트를 찾아 삭제하는 기능은 제공하지 않는다. 화면 문구도 이 범위를 “앞으로”로 명시한다.

표식 없는 수동 테스트, 자동화 탐지를 우회한 클라이언트, 위조 이벤트까지 완전히 식별할 수는 없다. 따라서 결과 이름은 ‘관측된 학습 활동’이며 ‘검증된 실제 이용자 수’가 아니다.

## 조회와 보관

```bash
docker exec leninbot-frontend node scripts/commulingo-learning-report.js 7
```

기간은 최근 1~30일. 콘텐츠·언어·모드별 시작 수, 답변한 라운드 수, 답변·정답 수, 완료 라운드 수, 마지막 활동을 JSON으로 출력한다. 기간 안에 수신된 이벤트를 집계하므로 기간 경계를 걸친 라운드는 시작과 완료의 분모가 다를 수 있다. 완료율을 계산할 때는 이를 주의한다. 데이터가 없으면 `rows: []`이며 과거 페이지 접속을 학습 이벤트로 소급하지 않는다.

운영 앱 시작 및 매시간 30일보다 오래된 이벤트를 삭제한다(시간 단위 정리 지연 가능). 개발 앱은 운영 데이터를 정리하지 않는다. 최초 적용에는 `scripts/migrations/180_commulingo_learning_events.sql`이 필요하다. 기존 진도 테이블의 INSERT 권한을 가진 역할에 새 테이블의 SELECT·INSERT·DELETE 권한을 부여한다.

## 검증

- `scripts/smoke-commulingo-measurement.js`: 제외 조건, Origin·JSON 보호, 입력 검증. `npm test`에 포함.
- `scripts/test-commulingo-measurement-db.js`: 실제 DB와 HTTP 라우트를 이용한 제외·중복·콘텐츠 검증. 테스트 기록은 트랜잭션 롤백한다.
- `scripts/test-commulingo-measurement-browser.js`: 미리보기 브라우저에서 시작 1회·답변·완료, 자동 로딩 무집계, 집계 거부, 테스트 모드, 모바일·데스크톱 표시를 확인한다. 자동화 계측을 시험할 때는 전송을 가로채고 운영 DB에 테스트 기록을 남기지 않는다.

API는 `POST /commulingo/measurement`. 익명 캐시 페이지에 CSRF 세션을 강제로 만들지 않으며, 대신 정확한 HTTPS Origin·JSON·사용자 정의 헤더를 요구한다. 기존 진도 저장 API의 CSRF 정책은 그대로 유지한다. 요청 제한은 IP당 분당 120회이며 IP는 이벤트 데이터에 보관하지 않는다.
