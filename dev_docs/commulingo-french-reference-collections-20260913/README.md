각 문헌의 제목·저자·해제·서지·전문·주석을 문헌집 안에 보존했다. 관련 인물·용어·사건 및 자동 링크 제외어는 세 문헌의 합집합을 사용한다. 목록의 기존 분류는 앞머리 문헌을 따른다. 최초 문헌의 연도로 정렬한다. 목차에서 개별 문헌으로 이동할 수 있다.

manifest의 `redirects`가 기존 12개 주소를 새 문헌집 안의 해당 글로 301 이동한다. 한국어·영어 주소 및 긴 문헌의 분할 페이지도 처리한다. 기존 문헌은 공개 목록·사이트맵에서 빠지지만 HTML은 보관한다. 『국가와 혁명』 제외 상태는 유지한다.

`verification.json`은 12편의 원본 해시와 통합 위치, `original-metadata.json`은 통합 전 메타데이터다. `manifest.prepared.json`과 이 폴더의 HTML은 검토본이며 `scripts/publish-french-reference-collections.py`로 공개한다. 공개 시 현재 manifest의 다른 항목은 유지하고 이번 12편과 네 문헌집만 갱신한다. `manifest.before.json`은 호스트에 보관하는 롤백용 백업이다.

최초 전체 테스트 및 독립 미리보기의 32개 화면·24개 기존 주소 이동 검증 통과. 브라우저 기록은 `browser-preview.json` 및 운영 확인 후 `browser-production.json`에 남긴다. 새 번역 API 호출은 없다.

이전 전문 번역 배치의 공개 기록은 통합 전 개별 문헌 기준의 역사적 기록이다. 통합 문헌의 후속 수정은 새 문헌집에도 반영해야 하며, 이전 등록 스크립트로 개별 문헌을 다시 등록하지 않는다.
