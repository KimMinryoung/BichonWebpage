# 입문 강좌 신규 데이터 등록 — 2026-09-13

현재 처리 완료: **42건 중 41건 공개(인물 6명, 용어 16개, 문헌 19편), 1건 사용자 요청으로 제외**. 오언 전문 번역을 DeepSeek Flash로 완료했다. 『국가와 혁명』은 국내 출판 도서이므로 참고문헌에서 제외했다. 기존 발췌 7편도 전문으로 교체했다. 최신 저본·검수·공개 기록은 [전문 번역 기록](../commulingo-fulltext-20260913/README.md)을 따른다. 아래 최초 등록 당시의 발췌 범위 설명은 해당 교체본에 적용하지 않는다.

## 등록과 검증

- 인물은 `scripts/commulingo-people-upsert`의 dry-run과 실제 Admin upsert를 통과했다. `people.json`이 제출 원본이며 승인 제안 ID는 9677~9682다. 인물 테이블에 직접 INSERT하지 않았다.
- 용어는 `commulingo-term-service.js`의 read → dry-run submit → submit → review 승인 경로를 거쳤다. `terms.json`, `term-receipts.json`에 제출 내용과 승인 결과가 있다.
- 문헌 공개본은 `data/commulingo/docs/`의 HTML과 manifest에 있다. `doc-receipts.json`은 19편의 등록 기록이다. 원어 전사·선택 범위·해시는 `specs/`, 실제 저본은 `sources/`에 보존했다.
- 기존 번역 파이프라인으로 비공개 초안을 생성한 후 조항·절의 범위, 핵심 주장과 논적 인용, 날짜·숫자 경고, 주석을 점검했다. `reviewed/*.review.json`에 수정 기록을 남겼다. 장문 전체에 대한 전문 번역가의 교열 완료를 뜻하지 않는다.
- 공개본에는 수동 교정과 주석 서식이 있으므로 해당 19개 스펙은 `frozen`으로 잠갔다. 재실행으로 교정본을 덮어쓰지 않는다.
- `npm test` 전체 통과(Node 20 지정 Docker 환경). 19편 모두 운영 origin에서 HTTP 200, 모바일 가로 넘침·깨진 주석 링크 없음. 공개 도메인에서도 최고가격법과 룩셈부르크의 주석 왕복을 브라우저로 확인했다. `browser-verification.json` 참고.
- `french-revolution-intro`, `socialist-divergences-intro`의 기존 입문 해설은 manifest에서 제외된 상태로 유지했고 `/commulingo/docs/<id>`가 404임을 확인했다. 이번에 공개한 문서는 원사료 번역이다.

## 저본·범위에서 확인한 차이

- 1791년 헌법에 앞선 1789년 권리 선언은 별도 문헌이다. Élysée 페이지의 현대 링크 문구는 법문에서 제거했다.
- 구주의 선언은 국민의회가 제공하는 도입문·서문·17개 조항이며 후기·헌정은 없다. 제목에 발췌를 명시했다.
- 생필품 연설은 전사본 앞부분의 괄호 삽입 진위를 확인하지 못해, 그 문장을 포함하지 않는 중후반부부터 결론까지 연속 발췌했다. 전문으로 등록하지 않았다.
- 정치도덕 보고의 1866년 베르모렐 선집은 편집자가 직접 축약 사실을 밝혔다. 발췌로 표시하고, 편집주에 인용된 1793년 12월 25일의 다른 보고를 섞지 않았다.
- 프레리알법은 채택 재록본의 제1~20조이며 임명자 명단이 빠져 있다. 다른 재록본의 제21조도 이 판본에는 없다. 발췌 제목과 서지에 명시했고 잘못된 제13조 번호를 대조 수정했다.
- 최고가격법은 『의회기록』 321~323쪽 인쇄 이미지와 OCR을 대조했다. 제1~20조, 가격·임금 상한, 징발, 벌칙을 모두 보존했다.
- 평등파 선언의 실제 채택 재록본은 1873년판이다. 초기 큐의 탐색 후보 판본과 구별했다.
- 베른슈타인의 「민주주의와 사회주의」는 채택 독일어 원판의 제4장 c절이다.
- 룩셈부르크 『사회개혁이냐 혁명이냐』는 MIA가 1908년 제2판에 따른다고 명시한 1982년 저작집 전사다. 『러시아 혁명』은 1918년 미완성 원고, 1922년 사후 발표, 2000년 저작집 제6개정판의 네 절과 저자 난외 메모를 채택했다. 영어판의 장 구분과 다르다.
- 『러시아 혁명』 제3절 뒤의 저자 메모 두 개가 원문 페이지의 이동 링크 아래에 있어 추출에서 빠진 것을 발견했다. 두 메모를 별도로 원문 대조 번역하여 복원하고 제4절의 메모와 섞이지 않도록 연결했다.
- 레닌은 제5장 전체다. 책 전체에서 고른 장이라는 의미와 장 내부 생략을 혼동하지 않도록 제목을 “제5장 전문”으로 했다.

## 오언 완료 및 제외 처리

오언 큐 1977은 DeepSeek Flash로 67개 청크 전체를 새로 번역하고 검토·공개하여 done으로 처리했다. 종전 Gemini 미완성 캐시는 재개하지 않는다. 과거 임시 스크립트 `/tmp/finalize_course_queue.py`는 오언 pending을 하드코딩하므로 재사용하지 않는다.

레닌 큐 1983은 사용자 요청으로 공개 문헌을 제외하고 resolved_id를 비웠다. 상태는 done을 유지해 자동 재등록을 방지한다. 나머지 최초 등록 자료는 보존했다.
