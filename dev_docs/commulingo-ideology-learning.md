## 해석 기준과 검수 범위

프랑스 혁명은 홉스봄의 『혁명의 시대』를 기본 해석틀로 삼는다. 법령의 규범, 실제 집행, 당사자의 주장, 역사가의 해석, 창작 문항을 구별한다. 이념에 동의하는지 대신 제시된 주장과 제도의 차이를 이해했는지 묻는다. 프랑스 혁명을 모든 현대 이념의 단일 기원으로 설명하거나 자코뱅파를 초기 볼셰비키로 취급하지 않는다.

새 문서는 비판자의 분류만으로 상대를 설명하지 않고 당사자의 저작을 먼저 비교한다. 직접 논쟁·선행 구상·후대의 수용은 구별하며 확인하지 않은 계보 화살표는 만들지 않았다. 19세기 사회민주주의를 오늘날 특정 정당과 동일시하지 않는다.

## 검증과 남은 범위

문서 구조·중복 ID·내부 앵커·문항 수를 검사했다. 저장소 `npm test` 전체 통과. 공개 브라우저에서 두 문서 HTTP 200, 27개 해설의 키보드 펼침·접힘, 접힌 목차를 통한 마지막 편 이동, 상호 링크를 확인했다. 360·390·1280·1600px의 밝은/어두운 테마에서 가로 넘침이 없었으며 모바일 첫 화면과 데스크톱 해설 화면을 이미지로 검토했다. 홈·문헌 목록 양쪽에서 두 문서 링크가 노출됐고 연결한 기존 원전·학습 세 경로도 HTTP 200이었다. 브라우저 페이지 오류는 없었다. 공개 후 관련 네 URL의 Cloudflare 캐시를 갱신했다.

한 편 약 4~5분은 편집상 예상이며 초심자 실측은 미완료다. 이번 9편은 입문 범위이며 멘셰비키·사회혁명당·평의회공산주의·트로츠키주의와 자유주의 각 분파를 모두 다룬 것은 아니다. 후속 확장 시 동일한 비교 질문과 당사자 문서 우선 원칙을 유지한다.
