# CommuLingo 혁명사와 사회주의 비교 학습

2026-09-13. 두 묶음을 실제 학습 강좌로 등록했다. 사용자의 수정 지시에 따라 가상 토론·가상 사료·인공 사례를 모두 제거하고 실제 법령·사건·저작을 묻는 42문항으로 다시 작성했다.

| 학습 경로 | 원본 | 구성 |
| --- | --- | --- |
| `/commulingo/book/french-revolution-intro` | `course/french-revolution-intro`(데이터 문서) | 10편·30문항: 1789년 구체제 붕괴, 1791년 헌법, 시민권·식민지 해방, 공화정 성립, 연합국 전쟁·방데전쟁·국민총동원, 생존권, 혁명재판, 로베스피에르의 숙청·몰락, 평등파, 테르미도르·총재정부·브뤼메르 |

한국어와 영어로 제공한다. 프랑스 혁명은 홈의 ‘역사’ 카테고리, 사회주의의 분기와 마르크스주의와 성 이론은 ‘사상 논쟁’ 카테고리(`category: 'theory'`, 2026-10-22)에 있다. 주제 분류(`category`)는 학습 형식(`format: 'short-learning'`)과 별개이며 강좌·레슨 ID를 변경하지 않는다. 각 편은 기존 플레이어의 **개념 설명 → 3문항 → 정오·선택지별 해설 → 오답 재도전 → 완료 기록** 흐름을 사용한다. 각 해설은 실제 근거 자료로 연결된다. 첫 문항을 별도 진단용 비채점 문항으로 처리하지 않으며, 세 문항 모두 기존 채점 방식으로 기록된다. 아직 모르겠어요 전용 버튼은 이번 범위에 없다.

사용자 요청으로 두 참고 문헌은 사이트에서 비공개 처리했다. 공개 `docs/manifest.json`에서 등록을 제거하고 메타데이터를 `docs/unpublished.json`에 보관했다. HTML은 편집용으로 남기며 공개 문서 주소는 404, 목록·자동 링크·사이트맵에서는 제외된다. 강좌의 출처 URL은 실제 사료·저작으로 연결하며 학습과 진도 ID는 유지한다. 초기 1~3편 초안은 현재 강좌의 원본이 아니다.

## 저장·구현

- 컬렉션 `format: 'short-learning'`: 편당 basic 레슨 하나, 3문항, 선택지 3개. 다른 강좌의 기본·심화/각 5문항/4지선다 규칙은 유지한다.
- `data/commulingo/shards.js`의 공개 한도와 `scripts/validate-commulingo.js`의 예상 수량에 등록했다. 레슨 ID는 `<강좌 ID>-ch01-basic` 형태이고 문항 ID는 `q1`~`q3`이다.
- 문항 `source.kind: 'reference'`는 직접 인용문 없이 출처만 연결한다. `quote`를 금지하여 요약을 원문 인용처럼 표시하지 않는다. 기존 원전 인용 형식은 그대로 동작한다.
- `public/js/commulingo.js`의 출처 링크 렌더링과 `public/js/commulingo-index.js`의 홈 그룹은 코드 배포 대상이다. 데이터 추가 후 샤드를 미리 생성한다.
- 프랑스 강좌의 조문 번호가 소련 헌법 6조로 오연결되지 않도록 `noAutoLink`를 컬렉션·샤드·학습 해설·사전 칩에 일관되게 적용한다.
- 프랑스 혁명의 테르미도르가 사전의 소련사 개념인 `soviet-thermidor`로 연결되지 않도록 한국어·영어 자동 링크도 차단한다.
- 완료·오답 기록은 기존 브라우저 저장과 로그인 계정 동기화 경로를 재사용한다. 신규 기록 스키마나 계측은 추가하지 않았다. 완료 기록의 새로고침 유지와 학습 도중의 문항 위치 복원은 다른 기능이다.

## 해석 기준과 검수 범위

프랑스 혁명은 홉스봄의 『혁명의 시대』를 기본 해석틀로 삼는다. 법령의 규범, 실제 집행, 당사자의 주장, 역사가의 해석, 해설의 요약을 구별한다. 이념에 동의하는지 대신 제시된 주장과 제도의 차이를 이해했는지 묻는다. 프랑스 혁명을 모든 현대 이념의 단일 기원으로 설명하거나 자코뱅파를 초기 볼셰비키로 취급하지 않는다.

사회주의 비교 강좌는 비판자의 분류만으로 상대를 설명하지 않고 당사자의 저작을 먼저 비교한다. 직접 논쟁·선행 구상·후대의 수용은 구별하며 확인하지 않은 계보 화살표는 만들지 않았다. 19세기 사회민주주의를 오늘날 특정 정당과 동일시하지 않는다.

## 2026-09-13 프랑스 혁명사 보강

강좌의 표시 이름을 **「프랑스 혁명 입문」에서 「프랑스 혁명사」로 변경**했다. URL과 강좌·레슨 ID는 저장된 진도와 외부 링크를 위해 유지한다. 먼저 기존 8편·24문항의 본문·도표·문항·선택지별 해설에 다음 내용을 보강했다. 이어 챕터가 늘지 않았다는 사용자 지적을 반영해 전쟁·총동원과 로베스피에르의 숙청·몰락을 독립 편으로 추가하여 10편·30문항으로 확장했다.

- 1789년 이전: 7년전쟁 뒤 영국 견제와 1778년 미국 독립전쟁 참전, 전쟁 채무와 막힌 조세개혁.
- 1791~1792년: 망명귀족과 필니츠 선언, 프랑스의 대오스트리아 선전포고, 초기 패전과 국왕의 거부권, 브룬스윅 선언·침공·발미·공화정 성립.
- 1793~1794년: 연합국 전쟁과 방데전쟁, 국민총동원령, 국민공회·공안위원회·치안위원회·혁명재판소의 권한, 로베스피에르의 공포 정당화와 정적 숙청, 프레리알법 뒤 47일간 파리의 1,376명 처형.
- 1795~1799년: 총재정부의 군대·쿠데타 의존, 이탈리아 원정의 자매공화국과 점령·기여금이라는 양면, 전쟁으로 부상한 보나파르트와 브뤼메르의 군사적 정권교체.

공포정치는 로베스피에르 한 사람의 사적 명령으로 축소하지 않되, 그가 공안위원회의 유력 위원으로서 억압을 공개적으로 정당화하고 에베르파·당통파 숙청과 프레리알법 확대에 책임이 있었다는 점을 구체적으로 적었다. 반대로 전쟁과 내전의 위기는 비상권력의 배경이지 모든 체포와 처형의 필요성을 자동으로 입증하지 않는다고 구별했다. 강좌 revision은 3이다.

## 2026-09-13 파벌 관계도와 에베르 인물 카드

강좌 첫 화면에 정치세력을 현대 정당처럼 평면화하지 않는 네 층 관계도를 추가했다. 1층은 푀양파와 왕정복고·망명귀족·선서거부 성직자·방데/슈앙 계열을 구분한 혁명 우파와 반혁명 세력, 2층은 국민공회의 산악파·평원파·지롱드파, 3층은 앙라제·상퀼로트와 코르들리에·자코뱅 클럽, 4층은 산악파 집권기 주변의 에베르파·로베스피에르파·당통파 경쟁이다. 각 카드는 핵심 입장·전환점·주요 인물을 보여주며 1791년 푀양파 분리부터 1794년 테르미도르까지 다섯 장면을 이어 붙인다. 파벌에 자의적인 색이나 점선 의미를 부여하지 않고, 각 층 위에 배치 축을 명시해 당시의 좌측에서 우측 순서로 배열한다. 한영 화면과 모바일 단일 열을 지원하고 인물 카드가 있는 이름은 새 탭으로 연결한다. 강좌 revision은 9이다.

자크 르네 에베르는 직접 SQL이 아닌 `scripts/commulingo-people-upsert`와 공통 editorial service를 통해 등록했다. 프랑스 국립도서관 전거·라루스·프랑스 국민의회 자료를 근거로 이름, 1757–1794년, 프랑스 시민권·국적 배경, 코르들리에와 『페르 뒤셴』, 파리 코뮌, 1794년 3월 숙청을 기록했다.

## 검증과 남은 범위

`npm test` 전체 통과. 추가 smoke 검사는 42문항의 실제 출처, 가상 시나리오 부재, 기존 강좌 규칙 보존, 선택지별 피드백 정렬·개수, 위험한 출처 URL 거부와 요약/인용 구별을 확인한다. 프랑스 혁명 강좌는 기존 8개 레슨 ID를 유지하고 두 레슨을 추가했으므로 저장된 진도와 복습 기록이 이어진다. 공식 배포 후에는 실제 운영 브라우저에서 두 강좌 합계 14편·42문항의 키보드 답변, 정오 채점, 근거 링크, 오답만 재도전, 완료 기록의 새로고침 유지, 홈의 두 강좌 노출, 자료 페이지 연결, 한국어·영어 화면을 확인한다. 360·390·1280·1600px 밝은/어두운 테마에서 가로 넘침도 검토한다.

## 2026-11-01 장 카드 형식

책 페이지의 장 카드는 제목·소요 시간, 한 줄 핵심(`learningFocus`), 읽는 문헌 칩(`readings`) 순서다. 소요 시간과 문헌은 산문이 아니라 필드다.

- `chapter.minutes`: 정수(분). summary 앞의 `약 12분 · ` / `About 12 minutes · ` 접두는 없앴고, 저장 게이트(`data/commulingo/course-validation.js`)가 다시 넣는 것을 거부한다.
- `chapter.readings`: `[{ author?: {ko,en}, title: {ko,en}, year, endYear? }]`. 한국어 제목에 『』·「」를 넣어 저장한다. readings가 있는 장은 카드에서 summary를 빼고(같은 문헌을 산문으로 나열할 뿐이라서) 레슨 시작 화면에만 보인다.
- `learningFocus`는 그 장의 갈림이나 결론을 한 문장으로 쓴다. 「~로 읽기 쉽습니다」 식 오해 정정문은 카드에 두지 않는다. 오독 바로잡기는 문항의 보기별 해설(`choiceFeedback`)이 맡는다.

short-learning 세 강좌(사회주의의 분기·프랑스 혁명·성과 젠더 33장)의 learningFocus를 한 줄로 다시 쓰고 readings를 넣었다. guided-reading 10강좌(73장)도 같은 형식으로 learningFocus를 새로 쓰고, readings에 그 장이 읽는 대목(예: 『루이 보나파르트의 브뤼메르 18일』 제5장)과 직접 읽는 다른 문헌을 넣었다. 『자본』 세 권은 기존 한 줄 learningFocus를 그대로 두고 readings에 권·장을 넣었다. 시간이 적혀 있지 않던 『자본』과 『유물론과 경험비판론』의 minutes는 추정치다: max(문항 수, 한국어 본문 글자 수 / 450). 작업본은 `scripts/content/chapter-card-redesign/`.

readings의 `doc`(사이트 참고 문헌 id)과 `anchor`(읽는 절)는 전문이 사이트 문헌에 있을 때만 넣는다. 매핑은 데이터에만 있고 페이지는 링크를 그릴 뿐이며, 저장 게이트(`sourceProblems`)가 문헌과 앵커가 실제로 있는지 확인한다. guided-reading 강좌의 첫 reading 앵커는 장의 `sourceUrl`과 같다. 『자본』·푸코처럼 사이트에 전문이 없는 문헌은 링크 없는 칩으로 남는다. 저작권이 살아 있어 사이트에 올리지 않는 글(1956년 이후 사망·생존 저자)은 `url`로 외부 원문(아카이브·출판처)을 걸 수 있다(2026-11-01). 칩이 새 탭으로 열리고 ↗ 표시가 붙는다. `doc`과 `url`은 함께 쓰지 않는다.

강좌 소개·배지에 「한 문단씩 끊어 읽습니다」, 「원문 끊어 읽기」 같은 진행 방식 문구를 쓰지 않는다(배지는 「원문 읽기 · N편」).

카드 높이는 내용대로 둔다(고정 `min-height` 없음). 레슨이 하나뿐인 장은 기본/심화를 고를 일이 없으므로 「기본」 라벨을 레슨 버튼·학습 화면 배지·다음 학습 안내에서 뺀다(`soleLevel`).

## 2026-11-01 결정사(decision-history) 형식 개편

「러시아 혁명사」·「소련사」 갈림길 책의 사실 정보를 산문 대신 필드로 옮겼다. 내용 보강(새 갈림길) 전에 형식을 먼저 확정한 것이다.

- 갈림길 `date`: `{ start: [y, m?, d?], end?, calendar?: 'julian'|'gregorian' }`. 화면이 「1905년 1월 9일 (구력)」, 「1928~1929년」, 「1906년 2월~4월」로 그린다(`dateLabel`, `public/js/commulingo-decision.js`). 1918년 2월 전 러시아 날짜는 날짜까지 적힌 경우 `julian`.
- 부(era) `years: [시작, 끝?]`이 `range` 산문을 대신한다.
- `eventIds: [사건 id]`가 `historyEventId` 하나를 대신한다(여러 사건 가능). `sources: [{ doc, anchor? }]`는 그 갈림길에서 읽을 사이트 문헌이다. 페이지는 서버가 넘기는 `refs`(문헌·사건 제목, `decisionRefs` in `data/commulingo/book-page.js`)로 칩을 그린다.
- 선택지는 2~4개, `stance`는 선택이다(없으면 성향 집계에서 빠짐). 한 입장에 한 선택지라는 제약을 풀었다. 기존 28편은 그대로 세 선택지다.
- 판정: 갈림길을 하나라도 결정하면 성향 막대·우세 노선·부별 표를 「갈림길 N개 중 n개 기준」으로 보여 준다. 실제 역사와의 일치는 색 사각형(일치·다름)으로만 표시하고 판정 낱말을 쓰지 않는다.
- 저장 게이트(`checkSpecialCourse`·`sourceProblems`, `data/commulingo/course-validation.js`)가 날짜·연도 모양, 선택지 수·id 중복, `actualId`, 입장 id, 문헌·앵커·사건의 실재, 한국어 텍스트의 줄표(—)를 검사한다.
- 기존 두 책의 한국어 줄표(—)를 쉼표·쌍점·문장 나눔으로 바꿨다. 작업본은 `scripts/content/decision-format/`.
