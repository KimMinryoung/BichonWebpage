# 인물 등록의 국가 분류 기준 (2026-09-07)

소속 국가(citizenship)는 실제 소속 국가, 출신 배경(nationalOrigin, legacy origin)은 출처로 확인한 민족·국가적 배경이다.

공통 정책은 `data/commulingo/nationality-policy.json`. Soviet/Yugoslav는 소속 국가 전용이며 Admin 생성·수정 검증에서 출신 배경으로 저장할 수 없다. Python 등록 스키마도 동일 제외 목록을 읽는다.

출생지·활동지·시민권만으로 출신 배경을 추정하지 않는다. 러시아 등의 자동 기본값을 사용하지 않는다. 혼합 출신은 한·영 label에 보존한다. 근거가 부족하면 추가 조사하거나 등록을 보류한다. 유지보수 프롬프트와 과거 일괄 보완 도구에서도 추정 기본값을 제거했다.

소련 시민의 출신 배경(2026-10-03): 여권·인사 기록의 민족(национальность) 기재를 우선한다(「다섯째 칸」은 엄밀히 인사 기록표의 항목 번호). 1938년 4월 NKVD 회람 이후 이 기재는 본인 신고가 아니라 부모의 민족을 따랐고, 1974년 여권 규정은 부모가 다르면 첫 여권(16세) 때 한쪽을 고른 뒤 바꿀 수 없게 했다. 기재가 출처에 없으면 부모의 민족으로 판단하고, 부모가 다르면 한·영 label에 둘 다 남긴다(「러시아 (우크라이나계 어머니)」). 모국어·성장지만으로 러시아로 분류하지 않는다. 예: 세르고 미코얀은 모스크바 출생·러시아어 화자지만 부모가 모두 아르메니아인이므로 아르메니아(「아르메니아계 (모스크바 출생)」). 인구조사는 본인 신고 민족이라 여권 기재와 다를 수 있다. 같은 문장이 `nationality-policy.json`의 `originGuidance`(등록 스키마 설명)와 leninbot `commulingo/classify.py`의 `ORIGIN_INSTRUCTIONS`(코드 자동 배정)에 있다. 배경은 용어 「소련 여권의 민족란」.

leninbot은 관리자 MCP로, CLI는 공통 편집 서비스로 같은 검증을 거친다.

회귀 검사: `node scripts/smoke-commulingo-nationality-policy.js` (소속 국가 허용, 출신 배경/별칭 거부, 구체 국가 허용, 혼합 설명 유지).

국가 코드 차단은 기계적으로 검증하지만, 사료의 신뢰도와 혼합 출신의 대표 국가 선택은 근거 검토가 필요하다.
