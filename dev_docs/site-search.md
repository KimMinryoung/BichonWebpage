# 통합 검색

2026-10-11 도입. 코드: `services/site-search.js`(검색), `routes/search.js`(화면), `views/public/search.ejs`, `views/partials/site-search-box.ejs`.

## 범위와 주소

- `/search`: 사이트 전체. `/commulingo/search`: 공산링고만. 같은 서비스에 범위만 다르고, 결과 화면 위 탭으로 서로 오간다.
- 입구: 모든 페이지 툴바의 돋보기(공산링고 페이지에서는 `/commulingo/search`, 그 밖은 `/search`), 홈 소개 상자 아래 검색창, 공산링고 첫 화면의 사전 탭 아래 검색창.
- 분야 순서(소유자 결정): 글(보고서·큐레이션·일기장·비숑글, 사이트 전체에서만) → 강좌 → 역사 사건 → 참고 문헌 → 인물 → 용어.
- 분야마다 5건을 보여 준다. 더 있으면 머리 행 전체가 그 분야 목록(`?q=` 이어받음)으로 가는 링크다. 강좌는 자기 목록이 없어 같은 검색 화면에서 펼친다(`?more=courses`).
- 검색 결과 페이지는 `noindex, follow`이고 robots.txt에서도 막는다.

## 일치 기준

- 글은 목록에 보이는 것만 찾는다. 보고서·정적 페이지(`/p`)는 제목·요약, 큐레이션은 제목·출처·저자·매체·태그·선정 이유, 일기·비숑글은 요약이 없어 제목·본문. 긴 보고서 본문이 흔한 단어마다 걸리지 않게 하려는 것이다. 분야 목록의 검색창은 지금처럼 본문까지 찾는다.
- 강좌는 강좌 제목·부제와 각 장 제목. 사건·문헌·용어는 각 사전 검색(`utils/dictionary-search.js`), 인물은 인물 사전 검색(`utils/people-search.js`)을 그대로 쓴다.

## 영어

영어 화면에서는 영어판이 있는 메뉴와 항목만 찾는다. 메뉴 단위 판정은 `config/menu-languages.js`(`services/menu-views.js`의 메뉴 키와 같은 키, `scripts/test-site-search.js`가 키 일치를 검사)이고, 항목 단위는 각 글의 번역 여부다. 2026-10-11 조사: 참고 문헌은 목록 제목·요약만 영어이고 본문이 한국어라 `none`, 게임도 `none`. 메뉴의 영어 지원이 바뀌면 이 파일을 고친다.

같은 판정으로 영어 화면은 `none` 메뉴의 입구를 숨긴다(2026-10-11): 뷰 헬퍼 `menuShown(menu)`(`middleware/view-locals.js`)로 대문의 문헌 바로가기·게임 카드와 푸터 게임 아이콘을, `data/commulingo/dict-tabs.js`로 공산링고 사전 탭·크럼 바로가기의 문헌 탭을 뺀다. 본문 속 문헌 발췌·관련 자료 링크와 주소 직접 접근은 그대로 둔다.
