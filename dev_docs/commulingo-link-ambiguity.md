# 자동 링크의 의미 중복: 수정과 재발 방안

## 2026-09-08 데이터 수정

`world-war-i`의 1914년 ‘7월 위기’가 `july-days`(1917년 러시아)로 연결됐다.
표제어는 ‘7월 사태’였고 잘못 연결된 표현은 별칭이었다. 한국어·영어 별칭 모두
자동 연결 기본값을 사용했다. 조사 시 용어 976개 모두 link_expressions가 비어 있었다.

실행 기록: `scripts/one-off/fix-ambiguous-term-expressions-20260908.js`.
7개 용어의 모호한 이름을 `search`로 지정해 검색은 보존하고 자동 연결을 중지했다.
7월 사태·소비에트 문화혁명·리가 구호 협정은 표제어도 구체화했다.
나머지 대상은 1917년 러시아 연립정부, 벨로베자 협정, 1988년 제네바 협정,
1954년 파리 협정이다. 구체적인 표제어와 별칭은 자동 연결을 유지한다.
변경 직전 행 전체는 운영 컨테이너 `/tmp/commulingo-ambiguous-terms-1788860337791.json`에 백업했다.

문서 `afghanistan-decisions-1979-1989`에도 ‘제네바 협정’ 별칭이 있어 제거했다.
실제 감사에서 호치민의 1954년 베트남 문맥이 이 아프가니스탄 문서로 연결되는
후보를 확인했다. 문서 패스가 용어보다 먼저 실행되므로 용어만 고치면 남는 오류다.
‘리가 조약’은 현재 문서 패스에서 평화조약으로 연결되지만, 구호 협정의 같은 별칭도
검색용으로 제한해 다른 화면에서 구호 협정으로 잘못 연결되는 것을 예방했다.

이 작업은 위험 표현을 선별해 교정한 것이며 976개 용어 전체의 의미 검수 완료를 뜻하지 않는다.
`audit-link-fires.js`의 수치는 후보 매칭 수이며 실제 렌더링과 다를 수 있다.
이 스크립트는 현재 context 정책, 페이지별 noAutoLink, 자기 항목 제외 등을 완전히
재현하지 않으므로 최종 판단은 운영 렌더러와 브라우저에서 해야 한다.

## 후속 구현 제안 (아직 미구현)

1. **표제어·별칭에 같은 등록 규칙 적용.** 특정 사건·제도에는 국가·연도·주체를
   포함한 이름을 요구하고, 일반 개념 항목과 구별한다. 표제어도 안전성 심사를 면제하지 않는다.
2. **검색과 자동 연결 승인 분리.** 신규·수정 표현은 기본 search, 의미가 고유하다고
   검토된 표현만 auto. context는 같은 문맥에 구체적인 identity 표현이 있을 때만 허용한다.
   기존 전체 사전을 한꺼번에 차단하지 말고 감사 결과를 검토해 단계적으로 전환한다.
3. **문서·사건·용어 통합 충돌 검사.** 한국어 NFC·공백 및 영어 대소문자 정규화 후
   표제어↔별칭, 별칭↔별칭을 비교한다. 사전에 경쟁 항목이 없다고 고유한 것은 아니므로
   ‘월+위기’, 일반 정부명, 연도 없는 협정명 등의 의미 검토도 병행한다.
4. **저장 전에 실제 연결 변경 미리보기.** 공통 렌더러로 변경 전후 링크 대상과
   주변 문장·페이지·시기를 보여준다. 정책 없는 신규 표현이나 충돌은 자동 승인하지 않는다.
5. **정기 감사와 회귀 사례.** 1914년/1917년 7월 위기, 베트남/아프가니스탄 제네바 협정,
   서로 다른 국가의 연립정부, 평화/구호 리가 협정을 음성 사례로 저장한다.
   고유한 전체 이름이 정상 연결되는 양성 사례도 함께 검사한다.

현재 `registerAlias`는 같은 사전 내 정확히 같은 문자열의 중복 연결을 막는다.
그러나 사전 간 우선순위와 현실 세계의 동명이의어까지 해결하지는 않는다.
기존 `link_expressions`의 auto/context/search를 활용할 수 있으므로 새 차단 체계를
별도로 만들기보다 등록 경로·검토 도구와 감사 도구를 보강하는 편이 적절하다.

검증: `npm test` 전체 통과. 운영 한국어 및 `/en/commulingo/events/world-war-i`를
Playwright로 열어 `july-days` 링크 0개와 ‘7월 위기’/‘July Crisis’ 본문 보존을 확인했다.
용어 상세의 `July Days (1917, Russia)` 제목도 확인했다. 백업은 호스트 /tmp에도 복사했다.
