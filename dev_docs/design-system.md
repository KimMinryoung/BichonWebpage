# 사이트 디자인 기준

새 화면과 기존 UI 수정에 적용하는 기준이다. 현재 사용자 지시가 우선이며, 예외가 필요하면 해당 컴포넌트의 이유를 코드에 남긴다.

## 레이아웃

- 게임·도구처럼 넓은 작업 영역은 `ui-page-shell`을 사용한다. 사이트 상단 `.site-nav`와 좌우 바깥 경계를 맞추며, 별도 최대 폭·가로 margin·가로 padding을 추가하지 않는다. 게임 목록, 파업, 노노그램에 적용되어 있다.
- 카드·보드·위치 메뉴의 바깥 테두리가 공통 경계다. 글과 버튼의 숨 쉴 공간은 카드 내부 padding으로 확보한다. 중첩 컨테이너마다 여백을 더하지 않는다. 게임의 테두리 없는 제목·안내·일정·목표·행동·기록 영역은 `--content-inset`(모바일 16px, 넓은 화면 24px)으로 좌우 내부 여백을 맞춘다. 공산링고 사건·용어·인물 상세와 허브의 공통 섹션도 같은 값을 사용한다. 섹션 구분선은 전체 폭을 유지하고 제목과 본문만 안쪽으로 들인다. 기존 카드와 보드는 자체 padding을 유지하고, 위치 메뉴에는 별도 내부 여백을 더하지 않는다.
- 지도·관련 인물 카드·참고 문헌·관련 보고서처럼 자체 레이아웃과 내부 여백이 있는 영역은 `commu-section-wide`를 사용해 섹션의 전체 폭을 쓴다. 섹션 제목과 연표 본문은 `--content-inset`을 유지한다.
- 긴 글은 읽기 폭을 제한할 수 있다. 기존 `.container`와 `--content-default`, `--content-wide`, `--content-home`을 사용한다. 읽기 폭 제한을 게임·도구의 바깥 컨테이너에 가져오지 않는다.
- 이미지와 제목을 함께 배치하는 카드는 제목의 읽기 폭을 우선한다. 좁은 카드에서는 이미지와 제목을 위아래로 배치하고, 한글 제목은 어절 단위로 줄바꿈한다. 반응형 검증에 열 수가 바뀌는 경계 바로 전후도 포함한다.
- 모바일에서는 열을 쌓고 컨트롤을 줄바꿈한다. 표·큰 퍼즐은 해당 영역 안에서만 스크롤한다. 페이지 전체의 가로 넘침을 `overflow-x: hidden`으로 가리지 않는다.

## 색·글꼴·간격

- 기본 인상은 먹색과 크림색, 각진 1px 테두리, 평평한 면이다. 일반 카드와 버튼에 임의의 둥근 모서리·그라데이션·떠오르는 그림자를 추가하지 않는다.
- 원본 값은 `public/css/palette.css` 한 곳에서 관리한다. 화면 CSS는 `--bg-*`, `--text-*`, `--border`, `--link`, `--btn-*` 등 의미 기반 토큰을 사용한다. 다크·라이트 양쪽을 확인한다.
- 녹색은 주요 행동, 빨강은 위험·오류에 사용한다. 게임 그림과 보드의 주제색은 허용하지만 일반 UI로 확장하지 않는다. 상태는 색 외에 글·아이콘으로도 표시한다.
- 본문은 `--font-sans`, 제목은 필요할 때 `--font-display`, 코드와 수치는 필요할 때 `--font-mono`를 사용한다. 크기는 `--text-*`, 행간은 `--leading-*`를 우선한다.
- 관련 인물 카드의 긴 참여 설명은 `--text-sm`(14px)·`--leading-normal`(1.6)·보통 굵기를 사용해 인물명과 역할보다 낮은 위계로 표시한다.
- 간격은 `--space-*`, 읽기 영역의 좌우 간격은 `--gutter`를 우선한다. 새로운 일회성 값을 늘리기보다 공통 토큰을 재사용한다.

## 컴포넌트와 조작

- 공통 UI는 `public/css/ui.css`와 `views/partials/`에서 재사용한다. 도메인 CSS에는 게임판 등 고유한 표현만 둔다. 공통 규칙을 페이지 끝의 덮어쓰기로 복제하지 않는다.
- 상단 메뉴는 `--bar-height`를 사용한다. 위치 메뉴는 현재 위치와 돌아갈 경로를 일관되게 제공한다. 게임과 공산링고의 위치 메뉴는 상단 메뉴 아래 `--crumb-offset`(14px), 높이 `--crumb-height`(34px)를 공유한다. 위치 메뉴로 시작하는 페이지는 shell 상단 padding을 중복 적용하지 않는다.
- 일반 버튼은 `--control-height`(44px)를 기준으로 한다. 키보드 포커스가 보이고, 입력에는 label, 현재 선택에는 적절한 ARIA 상태를 제공한다. 퍼즐 셀 같은 공간 제약 컨트롤은 키보드 조작을 함께 제공한다.
- 차례는 번호와 제목을 한 링크 행에 넣고, 번호 앞에는 `--content-inset` 한 번만 적용한다. hover는 행 전체의 배경으로 표시하고 밑줄을 추가하지 않는다. 키보드 포커스는 행 안쪽 윤곽선으로 표시한다.
- hover는 배경·테두리·글자색으로 표현한다. 모션은 공통 시간 토큰을 사용하고 reduced-motion을 존중한다.

## 변경 검증

- UI 작업 전에 이 문서와 관련 공통 CSS를 확인한다. 새 규칙은 문서와 실제 공통 구현을 함께 갱신한다.
- 브라우저에서 모바일 360/390px, 데스크톱 1280px 이상과 넓은 화면을 확인한다. 다크·라이트, 긴 제목, 키보드 포커스, 가로 넘침을 점검한다.
- 게임은 `/games/`, `/games/strike/`, `/nonogram/`에서 상단 메뉴와 shell·주요 패널의 좌우 경계를 확인한다. 파업 시작 후 보드와 노노그램 확대 상태도 확인한다.
- 기존 게임 브라우저 검증은 `node scripts/test-games-ui.js`를 사용한다. 검증용 스크린샷은 `/tmp`에 저장하고 실제 이미지를 열어 확인한다.
