# CommuLingo 인물 별칭 표준

인물 별칭(`commulingo_person_aliases`)은 검색에만 쓰이는 숨은 데이터가 아니다. 상세 페이지 머리의 「다른 이름」과 검색 결과 카드의 「검색된 별칭」에 그대로 나오므로, 그 언어로 읽을 수 있는 **이름 자체**여야 한다. 규칙 본체는 `data/commulingo/person-alias-rules.js`이고, Admin 스토어(`people-admin-store.js`의 `replaceAliases`)가 쓰기 때 거부한다. 사후 점검은 `docker exec leninbot-frontend node /app/scripts/audit-person-aliases.js`로 한다(위반이 있으면 exit 1).

## 넣는 것

- 본명, 가명·필명·당내 가명·작전명, 결혼 전·결혼 후 이름
- 관용 약칭(표제어에 없는 형태), 널리 쓰인 다른 음역(보응우옌지압, Vo Nguyen Giap)
- 영어 칸의 이니셜 형태(V. I. Lenin, FDR)와 대소문자 변형(Douglas Macarthur — 영어 링크는 대소문자를 구분하므로 별도 형태다)
- 여러 단어로 된 성(드 골, de Gaulle, 폰 데어 골츠)과 링커가 성으로 믿지 않는 성(Mil — 로마 숫자로 읽힌다). 이런 성은 링커가 스스로 색인하지 않으므로 별칭으로 둔다.

## 넣지 않는 것

- **표제어, 부칭을 넣은 표제어, 한 단어 성.** 검색은 표제어 전체를 부분 문자열로 찾고, 링커(`people-linkify.js`)는 `familyName`을 스스로 후보에 넣는다. 예전에는 성으로 링크하려면 별칭 행이 있어야 해서 성만 있는 별칭이 대량으로 쌓였다. 링커가 성을 직접 색인한 뒤로는 중복이다.
- **설명과 꼬리표.** `이오페 (본명)`, `born Ivashutich`, `작전명 '스타릭'`처럼 괄호·따옴표·「본명/필명/born」을 붙이지 않는다. 구분을 보여줄 필요가 생기면 별도 필드로 만든다.
- **원어 표기.** 키릴·한자·그리스·아르메니아·조지아·히브리 문자 이름은 원어 이름 칸(`cyrillic`)의 몫이다. 원어로만 알려진 가명은 로마자(영어 칸)와 한글(한국어 칸)로 옮겨 넣는다(Жюль Элизар → Jules Elysard / 쥘 엘리자르).
- 틀린 철자, 일반명사(마이그레이션 194 트리거), 한 글자 별칭.

## 언어 칸

- 한국어 칸: 한글만 쓴다(숫자와 `.`·`·`·`-` 허용). 로마자 이니셜(`V. A. 쿠투조프`)이나 약어(`FDR`)는 영어 칸에 둔다.
- 영어 칸: 로마자만 쓴다(발음 구별 기호, 숫자, `. , - ' ’ ʻ &` 허용).
- 한 단어 안에 문자 체계를 섞지 않는다(`Р.М. Нуре예ф` 같은 깨진 값이 생기지 않게).

## 2026-10-03 일괄 정리

규칙을 도입하면서 Admin 경로(`scripts/commulingo-people-upsert`)로 1,912명을 고쳤다. 별칭은 8,837개에서 4,952개가 됐다.

- 표제어·한 단어 성 중복 3,563개를 지웠다. 지우기 전후 한국어·영어 링크 색인(`byAlias`, 문맥 이름, 성 약칭)이 완전히 같음을 확인했다.
- 괄호·꼬리표는 떼고 이름만 남겼다. 원어 표기는 지웠고, 원어로만 남아 있던 가명(크로폿킨·라브로프·트카초프·바쿠닌·먀스니캰·카민스키·수하노프)은 한글과 로마자로 옮겼다.
- 한국어 칸의 로마자 형태는 영어 칸에 없을 때 영어 칸으로 옮겼다. 한국어 칸 이니셜은 뗐다. 떼고 나서 남은 것이 표제어의 변형일 뿐이면 지웠고, 가명이면 성만 남겼다(`A. 조린` → `조린`).
- 몽골 인물의 전체 이름 키릴 표기(`Балингийн Цэрэндорж`)도 원어 표기라 지웠다. 한글·로마자 전체 이름은 별칭에 남아 있다.
