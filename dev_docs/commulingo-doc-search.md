# CommuLingo 참고 문헌 안 검색 (2026-10-09)

- 리더 상단 바의 「검색」(목차 오른쪽)은 문헌 하나의 모든 페이지를 찾는다. 긴 문헌은 약 12만 자씩 `?p=N`으로 나뉘어 브라우저 찾기가 지금 페이지만 보기 때문이다. 짧은 문헌도 같은 패널을 쓴다.
- 서버: `GET /commulingo/docs/:id/search?q=` → `data/commulingo/doc-search.js`. 렌더되는 본문(페이지별 HTML, 단일 페이지면 제목 h1 뒤)을 텍스트로 바꿔 문헌 본문 캐시 항목(`getCommuLingoDocContent`)에 WeakMap으로 붙여 둔다. 결과는 페이지별 개수와 앞 300곳의 발췌(절 제목 포함). 300만 자 문헌도 0.2초 안팎.
- 화면: 결과를 누르면 `?p=<쪽>&q=<검색어>&hit=<그 쪽 안의 순번>`으로 간다. `public/js/commulingo-doc-search.js`가 본문(`.doc-body`)의 일치를 모두 `mark.doc-hit`으로 감싸고 고른 곳(`is-current`)으로 스크롤하며, 아래 막대(↑↓)가 페이지를 넘나들며 이어 간다.
- **정규화 계약**: 서버와 클라이언트가 같은 규칙으로 센다 — 태그는 공백 없이 지움(인접 텍스트 노드가 붙음), 엔티티 복원, 공백 연속은 한 칸, 글자별 소문자화(길이가 바뀌는 글자는 그대로), 겹치지 않는 일치. 한쪽을 바꾸면 다른 쪽도 같이 바꾼다. `scripts/smoke-commulingo-doc-search.js`가 서버 쪽을 검사한다. 2026-10-09 브라우저 대조(예조프 평전·스페인 내전 문헌 등 7편, 페이지별 서버 개수 = 화면 표시 개수) 통과.
